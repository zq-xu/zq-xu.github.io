# Dates, Weekdays, Months, and Seasons

## 1. Days of the Week

| English | Malti |
|---|---|
| Monday | it-Tnejn |
| Tuesday | it-Tlieta |
| Wednesday | l-Erbgħa |
| Thursday | il-Ħamis |
| Friday | il-Ġimgħa |
| Saturday | is-Sibt |
| Sunday | il-Ħadd |

`nhar` (day) is often used before a weekday, for example `nhar it-Tnejn` (on Monday). The definite article is commonly retained.

## 2. Months

| English | Malti |
|---|---|
| January | Jannar |
| February | Frar |
| March | Marzu |
| April | April |
| May | Mejju |
| June | Ġunju |
| July | Lulju |
| August | Awwissu |
| September | Settembru |
| October | Ottubru |

`f'` is commonly used before a month: `f'Mejju` (in May), `f'Ġunju` (in June). Month names are written as regular nouns in sentences; they are capitalized uniformly here for lookup.

## 3. Seasons, Years, and Relative Dates

| English | Malti |
|---|---|
| spring | rebbiegħa |
| summer | sajf |
| autumn; fall | ħarifa |
| winter | xitwa |
| year | sena |
| next year | is-sena d-dieħla |
| last year | is-sena l-oħra |

Common forms with seasons include `fir-rebbiegħa` (in spring), `fis-sajf` (in summer), `fil-ħarifa` (in autumn), and `fix-xitwa` (in winter). Years can be written numerically, for example `fl-2026` (in 2026).

### Last/This/Next Week, Month, and Year

| English | Malti |
|---|---|
| last week | il-ġimgħa li għaddiet |
| this week | din il-ġimgħa |
| next week | il-ġimgħa d-dieħla |
| last month | ix-xahar li għadda |
| this month | dan ix-xahar |
| next month | ix-xahar id-dieħel |
| last year | is-sena l-oħra |
| this year | din is-sena |
| next year | is-sena d-dieħla |

`li għadda` means “that has just passed/last,” `li jmiss` can mean “next,” and `d-dieħel` is often used for a coming month or year. Interpret relative time expressions together with the tense and context.

## 4. Date Formats

Before weekdays, months, and seasons, prepositions often contract with the definite article. A common date order is “day + `ta'` + month + year,” for example `14 ta' Ottubru 2026` (14 October 2026). Use `nhar` to introduce a weekday, as in `nhar it-Tnejn` (on Monday). To avoid ambiguity between day/month conventions, write the month name in full in formal itineraries. Relative week, month, and year phrases are listed above.
