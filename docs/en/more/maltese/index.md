# Maltese Learning Index

This folder gathers Maltese learning materials, organized by topic in subfolders.

## Learning Materials

1. [Grammar and Foundations](grammar/index.md): basic vocabulary, useful phrases, verb conjugation, tenses, numbers, time, dates, and prepositions.
2. [Reading and Word-by-Word Practice](practice/index.md): Maltese dialogues and emails, each shown in full before the sentence translations and word notes.
3. [Topic Analysis and Practice](modules/index.md): learning and practice on different topics.

## Suggested Order

Start with [Grammar and Foundations](grammar/index.md) to learn common vocabulary and grammar. Then use [Reading and Word-by-Word Practice](practice/index.md) to work through dialogues and emails, reinforcing the language with sentence translations and word notes.
