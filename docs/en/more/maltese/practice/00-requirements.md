# Maltese Practice Document Requirements

This resource is for beginner Maltese learners. Each practice text should be shown in full first. Names in the text should use English or Maltese spelling. The text should then be translated sentence by sentence, with word-by-word explanations. Save each topic in its own Markdown file and provide directory pages.

## Dialogues

1. A two-person dialogue about making a hospital appointment.
2. A two-person dialogue about lost property and arranging a time to collect it at the police station.
3. A two-person dialogue about attending a weekend party.
4. A two-person dialogue asking the current time.
5. A two-person dialogue about plans for today, tomorrow, this weekend, next week, next month, and next year.

## Emails

1. An invitation to a birthday party.
2. A reply to a birthday party invitation.
3. An invitation to a wedding.
4. A reply to a wedding invitation.
5. An invitation to dinner.
6. A reply to a dinner invitation.

## Document and Formatting Requirements

- This requirements document is the first Markdown document.
- Put dialogues and emails in separate folders: `dialogues/` and `emails/`.
- Create one Markdown file per dialogue or email topic. Number files within each category, starting at `01` and following the requested order.
- Provide a root index and a separate index page in each category folder.
- Show each complete Maltese text before its sentence-by-sentence translation and word notes.
- Use English or Maltese spelling for names in the practice texts.
