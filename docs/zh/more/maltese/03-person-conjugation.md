# 动词人称变位
 
## 1. 人称标记与变位公式
 
马耳他语动词根据主语的人称和单复数改变形式。代词通常可以省略，因为动词形式往往已经标出人称；需要强调或对比时再说出代词。`hu`（他）和 `hi`（她）区分第三人称单数的阳性/阴性，`inti`（你，单数）对男女都可使用。
 
常见形式可概括为“人称前缀 + 动词词干”：第一人称常见 `n-`，第二人称常见 `t-`，第三人称阳性常见 `j-`；第三人称阴性常与第二人称单数同形。复数常用复数词干或 `-u` 词尾。以 `kiteb`（写）为例：
 
| 人称 | 代词 | 常见标记 | `kiteb` 的形式 |
|---|---|---|---|
| 第一人称单数 | jien | n- | nikteb |
| 第二人称单数 | inti | t- | tikteb |
| 第三人称单数阳性 | hu | j- | jikteb |
| 第三人称单数阴性 | hi | t- | tikteb |
| 第一人称复数 | aħna | n- + 复数词干 | niktbu |
| 第二人称复数 | intom | t- + 复数词干 | tiktbu |
| 第三人称复数 | huma | j- + 复数词干 | jiktbu |
 
这是常见模板，不是对所有动词都适用的机械公式；词根类型和词干变化需要逐词记忆。
 
### `għ` 的位置与词干变化
 
- 词根以 `għ` 开头时，人称前缀接入后，`għ` 通常仍保留在拼写中，但词干元音可能变化，例如 `għen` → `ngħin`、`għex` → `ngħix`。
- 词根中间含 `għ` 时，`għ` 通常保留在拼写中，前后元音或词干可能变化，例如 `bagħat` → `nibgħat`、`qagħad` → `noqgħod`、`biegħ` → `nbiegħ`。
- 因而可以记为“人称前缀 + 对应词干模板”；`għ` 词没有适用于所有词根的字符替换公式，应按具体动词记忆。

表达身份时，马耳他语通常不单独使用系词“是”，例如 `Jien student.`（我是学生。）
 
## 3. 性别与一致
 
- `hu` 和 `hi` 区分阳性、阴性；第三人称动词也可能区分性别，如 `jikteb`（他写）与 `tikteb`（她写）。
- 第二人称单数 `inti` 对男女都可用，动词形式在上述例子中相同。
- 名词和形容词可能发生性数一致：`tifel tajjeb`（好男孩）、`tifla tajba`（好女孩）。
- 复数的人称动词常使用特定词尾，但不要把一个动词的变位直接推广到所有词根。
 
## 4. 练习模板
 
把动词替换进下面的句型，再改变主语：
 
- `Jien ___ il-ħobż.`：我……面包。
- `Hi ___ l-ilma.`：她……水。
- `Aħna ___ id-dar.`：我们……回家/在家。
 
动词形式和例句应一起记忆；遇到不规则或借词动词，优先查完整变位表。
