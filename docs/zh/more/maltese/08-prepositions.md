# 常用介词与用法
 
介词常和名词、定冠词连用；一部分会与后面的定冠词缩合。介词也可以带人称后缀，形成“对我/和你/在他那里”等形式。下表大致按日常使用频率排序；具体频率会随语境和搭配变化。
 
## 1. 常用介词表
 
下表先列日常高频介词，再列常见的方向、时间、例外和固定搭配形式。马耳他语词典还会把少见方言、古语、连词用法及屈折形式归入介词条目；本表以现代标准语中实用的介词和介词短语为主。

## 3. 方向、来源与位置
 
- `immur Malta`：我去马耳他。（地名搭配不一定需要冠词）
- `niġi minn Malta`：我来自马耳他。
- `Il-ktieb qiegħed fuq il-mejda.`：书在桌子上。
- `Il-qattus qiegħed taħt is-sodda.`：猫在床下。
- `L-iskola tinsab ħdejn id-dar.`：学校在房子旁边。
 
## 4. 时间介词
 
- `filgħodu`：早上；`wara nofsinhar`：下午；`filgħaxija`：晚上。
- `f'Ġunju`：在六月。
- `nhar it-Tnejn`：星期一这一天。
- `qabel l-ikel`：午餐/吃饭之前；`wara l-ikel`：吃饭之后。
 
## 5. `għand` 表示“有”
 
马耳他语常用 `għand` 加人称形式表达“某人有某物”，不是直接用英语式的 have 动词：
 
| 中文 | Malti |
|---|---|
| 我有 | għandi |
| 你有 | għandek |
| 他有 | għandu |
| 她有 | għandha |
| 我们有 | għandna |
| 你们有 | għandkom |
| 他们/她们有 | għandhom |
 
例句：`Għandi karozza.`（我有一辆车。）`Għandek kelb?`（你有狗吗？）
 
## 6. 学习建议
 
把介词和名词一起记，不要只背中文单义；`f'`、`għal`、`minn` 等词会根据上下文表达不同关系。也留意冠词和介词的缩合，如 `fil-`、`bil-`、`mal-`、`għall-`、`mill-`、`tal-`。
