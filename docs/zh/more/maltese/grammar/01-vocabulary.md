# 分类基础马耳他语词汇
 
本表按主题整理基础词汇，代词、亲属、房屋、动物、植物、交通、时间、疑问词、常用动词和介词十个核心类别各不少于 20 条；亲属称谓另作细分。需要变化的词形直接列在对应主题表中。马耳他语动词没有和英语 `to + verb` 一一对应的不定式；动词栏列出常见引用形式，实际造句时要根据主语变位。

## 小提示
 
- 形容词常有阳性、阴性形式，例如 `tajjeb`（阳性）和 `tajba`（阴性）。
- `x'` 常用于“什么”，如 `X'jismek?`（你叫什么名字？）；它通常和后面的词连写。
- 动词表中写出的不是所有人称通用形式。比如“我吃”是 `niekol`，“他吃”是 `jiekol`，详见[动词人称变位与人称代词](03-person-conjugation.md)。
