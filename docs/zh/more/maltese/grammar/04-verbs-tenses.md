# 动词与基本时态
 
本章按“规则说明 → 分时态变位 → 对照练习”组织。马耳他语常用未完成式表达现在、习惯或尚未完成的动作，完成式表达已完成的动作；将来通常用 `se + 未完成式`。这些形式与英语时态并非一一对应，具体时间仍需结合语境和时间词判断。
 
学习顺序：先理解未完成式和完成式如何构成，再看将来标记 `se` 如何与未完成式组合；然后分别学习三个时态，并在各节查看目标动词的人称形式和三语例句。人称前缀与单复数规律见[动词人称变位与人称代词](03-person-conjugation.md)。
 
## 1. 三种常见时态的构式
 
| 学习名称 | 马耳他语形式 | 常见用途 | 示例 |
|---|---|---|---|
| 现在/习惯：未完成式 | 人称形式 + 动词词干 | 当前状态、习惯或尚未完成的动作 | `Jien nikteb.`：我写/正在写。 |
| 过去：完成式 | 动词完成式的人称形式 | 已完成的动作或事件 | `Jien ktibt.`：我写了。 |
| 将来 | `se + 未完成式` | 计划、预测或将发生的动作 | `Jien se nikteb.`：我会写。 |
 
未完成式和完成式是形式/体貌范畴，不与英语现在时和过去时严格一一对应；上下文和时间词会共同确定具体时间。变位随人称变化，详细的人称规律见[动词人称变位与人称代词](03-person-conjugation.md)。
 
## 2. 未完成式与完成式
 
马耳他语动词系统常用“未完成式”和“完成式”来描述形式/体貌。入门时可以大致把未完成式理解为现在、习惯或未完成的动作，把完成式理解为已完成的动作（常对应过去）；这只是便于学习的近似，不是与英语时态的一一对应。马耳他语没有与英语 `to eat` 完全对应的不定式。
 
## 3. 现在或习惯动作：未完成式
 
常见动词会随人称改变前缀，也可能改变词尾。以“写” `kiteb` 为例：
 
| 人称 | Malti | 中文 |
|---|---|---|
| 我 | nikteb | 我写/我正在写 |
| 你（单数） | tikteb | 你写/你正在写 |
| 他 | jikteb | 他写/他正在写 |
| 她 | tikteb | 她写/她正在写 |
| 我们 | niktbu | 我们写/我们正在写 |
| 你们 | tiktbu | 你们写/你们正在写 |
| 他们/她们 | jiktbu | 他们/她们写/正在写 |
 
例句：
 
- `Jien nikteb ittra.`：我写一封信。
- `Hi taqra ktieb.`：她读一本书。
- `Aħna naħdmu hawn.`：我们在这里工作。
 
动作是否正在发生，通常由语境或时间表达说明；未完成式不只表示“此刻正在”。

## 4. 已完成动作：完成式
 
以“写” `kiteb` 为例，完成式常用作过去已完成动作：
 
| 人称 | Malti | 中文 |
|---|---|---|
| 我 | ktibt | 我写了 |
| 你（单数） | ktibt | 你写了 |
| 他 | kiteb | 他写了 |
| 她 | kitbet | 她写了 |
| 我们 | ktibna | 我们写了 |
| 你们 | ktibtu | 你们写了 |
| 他们/她们 | kitbu | 他们/她们写了 |
 
例句：
 
- `Ilbieraħ ktibt ittra.`：昨天我写了一封信。
- `Hu kiel il-ħobż.`：他吃了面包。
- `Morna r-ristorant.`：我们去了餐厅。
 
动词的完成式有词干变化；不能把某个动词的形式机械套到所有动词上。更多人称表见[动词人称变位与人称代词](03-person-conjugation.md)。

## 5. 将来
 
常见做法是在未完成式前加将来标记 `se`（也常见 `ser`）或 `ħa`。时间词如 `għada`（明天）也能帮助表达将来。
 
- `Għada se mmur Malta.`：明天我会去马耳他。
- `Se nikteb l-ittra.`：我将写这封信。
- `Ħa nieklu issa.`：我们现在要吃了。
 
`se`、`ser`、`ħa` 的使用会因口语习惯和语境而有差异；初学者先掌握 `se + 未完成式` 即可。

## 6. 否定与疑问入门
 
- 常见否定框架是 `ma ... x`：`Ma nafx.`（我不知道）；`Ma nifhimx.`（我不明白）。具体动词可能出现形态变化。
- 是非疑问句常通过语调或语境形成：`Titkellem bl-Ingliż?`（你会说英语吗？）
- 疑问词常放在句首：`Fejn tgħix?`（你住在哪里？）
 
## 7. 记忆方法
 
先记住动词“写”这一组的常见未完成式，再把“吃” `jiekol`、“读” `jaqra`、“工作” `jaħdem` 放进简单句。每学一个新动词，同时记一条“我”形式和一条“他/她”形式。
