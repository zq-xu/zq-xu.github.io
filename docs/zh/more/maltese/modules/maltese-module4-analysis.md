# Module 4: 购物与食物

**Ix-xiri u l-ikel — Shopping and Food — 购物与食物**


## 主题理解

| 原文 | 中文与逐词／短语解析 |
|---|---|
| Ix-xiri u l-ikel | 购物与食物。<br>**Module 4** 第四模块<br>**ix-xiri** 购物、购买（定冠词发生同化）<br>**u** 和<br>**l-ikel** 食物、饮食。 |
| Shopping and Food | 购物与食物。<br>**shopping** 购物<br>**and** 和<br>**food** 食物。 |

## 2 第 4 题：蔬果清单

**F’din il-kaxxa ikteb kemm tista’ frott u ħaxix li ssib mingħand tal-ħaxix.**

中文：在框里尽量列出可在蔬果店找到的水果和蔬菜。

- **f’din il-kaxxa** 在这个框里。
- **ikteb** 写。
- **kemm tista’** 尽可能多。
- **frott** 水果（集合）。
- **u** 和。
- **ħaxix** 蔬菜（集合）。
- **li ssib** 你找得到的。
- **mingħand tal-ħaxix** 从蔬果商那里。

参考答案：

- **tuffieħ** 苹果。
- **larinġ** 橙子。
- **banana** 香蕉。
- **lanġas** 梨。
- **għeneb** 葡萄。
- **lumi** 柠檬。
- **frawli** 草莓。
- **patata** 土豆。
- **basal** 洋葱。
- **tewm** 大蒜。
- **tadam** 番茄。
- **karrotti** 胡萝卜。
- **ħass** 生菜。
- **ħjar** 黄瓜。

### 第 5 题：肉店和鱼店

**F’din il-kaxxa ikteb kemm tista’ tipi ta’ laħam li ssib mingħand tal-laħam, u tipi ta’ ħut li ssib mingħand tal-ħut.**

中文：列出肉店出售的肉类，以及鱼店出售的鱼类。

- **tipi** 种类。
- **ta’ laħam** 肉的。
- **li ssib** 你找到的。
- **mingħand tal-laħam** 从肉店／肉贩那里。
- **u** 和。
- **ta’ ħut** 鱼的。
- **mingħand tal-ħut** 从鱼店／鱼贩那里。

| Tal-Laħam：肉类参考答案 | Tal-Ħut：鱼类参考答案 |
|---|---|
| **tiġieġ** 鸡肉<br>**ċanga** 牛肉<br>**majjal** 猪肉<br>**ħaruf** 羊羔肉<br>**fenek** 兔肉<br>**dundjan** 火鸡肉 | **tonn** 金枪鱼<br>**salamun** 三文鱼<br>**sardin** 沙丁鱼<br>**lampuki** 鲯鳅／当地常见的 lampuka 鱼（复数）<br>**awrat** 金头鲷<br>**spnott** 海鲈鱼 |

**注意：** `tal-laħam / tal-ħut / tal-ħaxix` 在日常语境可指经营这些商品的人或店家，不只是字面“肉的／鱼的／蔬菜的”。

### 口语任务一：穿什么

**It-Taħdit — X’se tilbes biex tmur...? (Jien se nilbes...)**

- **it-taħdit** 口语、说话。
- **x’** 什么。
- **se** 将要。
- **tilbes** 你穿。
- **biex** 为了。
- **tmur** 你去。
- **jien** 我。
- **nilbes** 我穿；区别于“你穿”tilbes。

| 情景与参考回答 | 中文与逐词解析 |
|---|---|
| Ix-xogħol? — Jien se nilbes qmis u qalziet għax-xogħol. | 去上班？——我会穿衬衫和裤子上班。<br>**ix-xogħol** 工作<br>**jien se nilbes** 我将穿<br>**qmis** 衬衫<br>**u** 和<br>**qalziet** 裤子<br>**għax-xogħol** 去上班（għal + 冠词；不是“因为工作”）。 |
| Il-baħar? — Jien se nilbes malja u sandli biex immur il-baħar. | 去海边？——我会穿泳衣和凉鞋去海边。<br>**il-baħar** 海／海边<br>**malja** 泳衣<br>**sandli** 凉鞋<br>**biex** 为了<br>**immur** 我去。 |
| Xi tieġ jew okkażjoni speċjali? — Jien se nilbes libsa sabiħa għal tieġ. | 去婚礼或特殊场合？——我会穿漂亮裙子参加婚礼。<br>**xi** 某个<br>**tieġ** 婚礼<br>**jew** 或者<br>**okkażjoni speċjali** 特殊场合<br>**libsa sabiħa** 漂亮的裙子<br>**għal tieġ** 为婚礼、参加婚礼。 |
| Tiekol f’restorant? — Jien se nilbes qmis u ġakketta biex immur niekol f’restorant. | 去餐厅吃饭？——我会穿衬衫和夹克去餐厅。<br>**tiekol** 你吃<br>**f’restorant** 在餐厅<br>**ġakketta** 夹克<br>**biex immur** 为了我去<br>**niekol** 我吃。 |

## 4 果蔬表补全与逐词解析

**Il-frott u l-ħaxix**：水果和蔬菜。

- **il-frott** 水果（集合名词）。
- **u** 和。
- **l-ħaxix** 蔬菜（集合名词）。

本页主要是词汇对照，每行一个词／短语，不必强行拆成句子。

| 原表词 | 马耳他语参考答案 | 中文与说明 |
|---|---|---|
| Cabbages | **kaboċċi** | 卷心菜；原表已给。 |
| Onions | **basal** | 洋葱；集合名词。 |
| Garlic | **tewm** | 大蒜。 |
| Potatoes | **patata** | 土豆。 |
| Cucumbers | **ħjar** | 黄瓜；单个可说 ħjara。 |
| Cauliflower | **pastard** | 花椰菜、菜花。 |
| Beans | **fażola** | 菜豆／豆类；蚕豆另可说 ful，种类有别。 |
| Pumpkins | **qargħa aħmar** | 南瓜的常见表达。<br>**qargħa** 瓜<br>**aħmar** 红色；该食材名称作为固定组合记忆。 |
| Peas | **piżelli** | 豌豆。 |
| Mushrooms | **faqqiegħ** | 蘑菇、菌菇。 |
| Carrots | **karrotti** | 胡萝卜；单数 karrotta。 |
| Lettuce | **ħass** | 生菜。 |
| Bell Peppers | **bżar ħelu** | 甜椒。<br>**bżar** 椒类<br>**ħelu** 甜的；也常按颜色区分。 |
| Spinich [原拼写] | **spinaċi** | 菠菜；英文标准拼写 spinach。 |
| Oranges | **larinġ** | 橙子；原表已给，指集合。 |
| Grapefruits | **grejpfrut** | 葡萄柚；借词表达，地区或词典可有异体。 |
| Lemons | **lumi** | 柠檬；单个可说 lumija。 |
| Apples | **tuffieħ** | 苹果（集合）；单个 tuffieħa。 |
| Banana | **banana** | 一根香蕉；多根可说 banana 作为集合或用可数形式，须结合语境。 |

| Grapes | **għeneb** | 葡萄（集合）。 |
| Watermelons | **dulliegħ** | 西瓜（集合）；单个 dulliegħa。 |
| Melons | **bettieħ** | 甜瓜（集合）；单个 bettieħa。 |
| Peaches | **ħawħ** | 桃（集合）；单个 ħawħa。 |
| Plums | **għanbaqar** | 李子（集合）。 |
| Strawberries | **frawli** | 草莓（集合）。 |
| Cherries | **ċirasa** | 樱桃的常见集合表达；具体可数形式另依语境。 |
| Tadam [原表已为马耳他语] | **tadam**；英文 tomatoes | 番茄（集合）；单个 tadama。不能把 Tadam 当成需译成马耳他语的英文。 |

## 15 题目逐词理解

**Imla l-vojt bin-numru t-tajjeb skont dak li hemm fil-parentesi u aqta’ linja taħt in-nom li jixraq.**

中文：根据括号中的数字填入正确数词，并在合适的名词下面画线。

- **imla l-vojt** 填空。
- **bin-numru t-tajjeb** 用正确的数词。
- **skont** 根据。
- **dak li hemm** 其中已有的内容。
- **fil-parentesi** 在括号里。
- **u** 并且。
- **aqta’ linja** 画线（整组表达）。
- **taħt** 在……下面。
- **in-nom** 名词。
- **li jixraq** 合适的。

示例：**Xtrajt tliet lanġasiet.** 我买了三个梨。

- **xtrajt** 我买了。
- **tliet** 三。
- **lanġasiet** 梨（可数复数）。

## 16 数词是否直接修饰名词

**X’inhi d-differenza bejn dawn?** 这些形式有什么区别？

- **x’inhi** 是什么（阴性）。
- **d-differenza** 区别。
- **bejn** 在……之间。
- **dawn** 这些。

| 独立形式 | 名词前形式 | 差别 |
|---|---|---|
| **erbgħa** 四 | **erba’** 四个…… | 独立读数／代指四个，对比直接修饰名词 |
| **sebgħa** 七 | **seba’** 七个…… | 同上 |
| **disgħa** 九 | **disa’** 九个…… | 同上 |
| **ħamsa** 五 | **ħames** 五个…… | 教材用这组更明显的词形帮助判断 |

### B. 完整补全与逐词解析

- **poġġi** 放入、写入。
- **l-kliem** 词语。

| 4. Ommi xtrat ratlejn basal u wiżintejn patata. | 妈妈买了两 ratal 洋葱和两 wiżna 土豆。<br>**ommi** 我的母亲<br>**xtrat** 她买了<br>**ratlejn** ratal 的双数（两个旧重量单位）<br>**basal** 洋葱<br>**u** 和<br>**wiżintejn** wiżna 的双数<br>**patata** 土豆。 |
| 5. Sentejn ilu sifirna darbtejn. | 两年前我们出国旅行过两次。<br>**sentejn** 两年<br>**ilu** ……以前（与前面时间组成“……前”）<br>**sifirna** 我们出国／旅行了<br>**darbtejn** 两次。 |
| 6. Il-ħajjata ħaditlu l-qies tal-ispallejn u t-tul tal-idejn biex tħitlu ġakketta. | 女裁缝量了他的双肩尺寸和双手臂长度，以便给他缝夹克。<br>**il-ħajjata** 女裁缝<br>**ħaditlu** 她给他取了／量了<br>**l-qies** 尺寸<br>**tal-ispallejn** 双肩的（按原题 ispalla 词形）<br>**u** 和<br>**t-tul** 长度<br>**tal-idejn** 双手／手臂的；这里按原题 id 转双数<br>**biex** 为了<br>**tħitlu** 她缝给他<br>**ġakketta** 夹克。 |

第 6 题按教材 `id` 作答；若要精确表达“手臂长度”，实际描述可用 `dirgħajn`，但那是措辞改写，不是本题括号词的双数答案。

## 18 数量表达与原例句

**L-Avverbji tal-Kwantità – Kemm?** 数量副词——多少？

- **l-avverbji** 副词。
- **tal-kwantità** 数量的。
- **kemm** 多少、多么。

教材将这些词集中在“数量副词”下学习，实际有些词也可作代词、限定数量的表达，须结合句中作用判断。

| 词语与原例句 | 中文与逐词解析 |
|---|---|
| Bilkemm — Bilkemm ilħaqt poġġejt bilqiegħda llum! | 几乎不／勉强——今天我几乎没来得及坐下来！<br>**bilkemm** 几乎不、勉强<br>**ilħaqt** 我来得及<br>**poġġejt** 我坐下了<br>**bilqiegħda** 坐着、就座<br>**llum** 今天。 |
| Biss — Agħtini erbgħa biss, mhux iktar. | 只有——只给我四个，不要更多。<br>**biss** 只<br>**agħtini** 给我<br>**erbgħa** 四个（独立）<br>**mhux** 不、不是<br>**iktar** 更多。 |
| Biżżejjed — Daqshekk biżżejjed! | 足够——这些就够了！<br>**biżżejjed** 足够<br>**daqshekk** 这么多、到这个程度。 |
| Ftit / naqra — Jien niekol ftit. | 一点——我吃得少。<br>**ftit** 一点、少量<br>**naqra** 一点（本页为数量表达，不是动词“我读”）<br>**jien** 我<br>**niekol** 我吃。 |
| Ftit li xejn — Lil Toni rajtu ftit li xejn. | 很少，几乎没有——我几乎没见到 Toni。<br>**ftit li xejn** 极少、几乎没有（固定短语）<br>**lil Toni** Toni（前置宾语）<br>**rajtu** 我见到他了（rajt + 宾语 -u）。 |
| Ħafna — Tina tħobb tgħum ħafna! | 很多／很——Tina 很喜欢游泳！也可按语境理解“常游泳”。<br>**ħafna** 很多、很<br>**Tina** 人名<br>**tħobb** 她喜欢<br>**tgħum** 她游泳。 |
| Iktar / iżjed — It-tarbija riedet iktar ħalib. | 更多——宝宝还想要更多牛奶。<br>**iktar / iżjed** 更多<br>**it-tarbija** 婴儿<br>**riedet** 她／它想要（阴性）<br>**ħalib** 牛奶。 |
| Inqas — Għandi inqas flus minnek. | 更少——我的钱比你少。<br>**inqas** 更少<br>**għandi** 我有<br>**flus** 钱<br>**minnek** 比你。 |
| Kollox — Għidli kollox! | 全部——把所有事情告诉我！<br>**kollox** 一切、全部<br>**għidli** 告诉我。 |
| Żejjed — Baqa’ ż-żejjed u rfajtu għal għada. | 多余的／剩下的——有多余的剩下来，我把它收好留到明天。<br>**żejjed** 多余的<br>**baqa’** 剩下了<br>**ż-żejjed** 剩余部分（名词化）<br>**u** 并且<br>**rfajtu** 我把它收好了（rfajt + -u）<br>**għal għada** 留到明天。 |

### 八题填空参考答案

**Imla l-vojt bl-avverbji tal-kwantità.** 用数量副词填空。

- **imla l-vojt** 填空。
- **bl-avverbji** 用副词。
- **tal-kwantità** 表数量的。

以下是一组语法与语境通顺的参考答案，允许重复用词；原题未说明“每词限用一次”。

| 补全句子 | 中文与逐词解析 |
|---|---|
| 1. Il-lejl li għadda, bilkemm irqadt. | 昨晚我几乎没睡。<br>**il-lejl** 夜晚<br>**li għadda** 刚过去的<br>**bilkemm** 几乎不<br>**irqadt** 我睡了。 |
| 2. Illum inħossni ħafna aħjar. | 今天我感觉好多了。<br>**illum** 今天<br>**inħossni** 我觉得自己、我感觉<br>**ħafna** 很多（加强比较程度）<br>**aħjar** 更好。 |
| 3. Jien għandi ftit ħbieb. | 我有几个朋友／我的朋友不多。<br>**jien** 我<br>**għandi** 我有<br>**ftit** 少量、几个<br>**ħbieb** 朋友（复数）。 |
| 4. Nixtieq li niltaqgħu iżjed drabi. | 我希望我们能更常见面。<br>**nixtieq** 我希望<br>**li** 引导从句<br>**niltaqgħu** 我们见面<br>**iżjed** 更多<br>**drabi** 次数。 |
| 5. Ilbieraħ ħadna ħafna gost! | 昨天我们玩得很开心！<br>**ilbieraħ** 昨天<br>**ħadna** 我们获得、享受了<br>**ħafna** 很多、很<br>**gost** 乐趣；ħadna gost 为“我们玩得开心”。 |
| 6. Kollox kien tajjeb u tgħidx kemm kilna! | 一切都很好，而且我们吃了好多！<br>**kollox** 一切<br>**kien** 当时是<br>**tajjeb** 好的<br>**u** 和<br>**tgħidx** 别说（否定命令式）<br>**kemm** 多少、多么<br>**kilna** 我们吃了；tgħidx kemm 为感叹用法，意为“可真不少”。 |

| 8. Xrobna ftit inbid aħmar. | 我们喝了一点红葡萄酒。<br>**xrobna** 我们喝了<br>**ftit** 少量<br>**inbid** 葡萄酒<br>**aħmar** 红色的。 |

- **żejjed** 多余的。

## 复习要点

1. 购物礼貌用语：**agħtini**（给我）、**jekk jogħġbok**（请）、**x’għandi nagħtik?**（我该付多少钱？）、**bqija**（找零）。
2. 配料表达：**gramma**（克）、**millilitru**（毫升）、**kuċċarina**（茶匙）、**nofs**（一半）、**ftit**（少许）。
3. 食谱常用命令：**itfa’**（放入）、**ħawwad**（搅拌）、**żid**（添加）、**farrak**（弄碎）、**ifrex**（铺开）、**aħmi**（烘烤）。
4. 穿着一致：**liebes**（男）、**liebsa**（女）、**libsin / lebsin**（复数）；颜色跟所修饰名词配合，不跟穿衣者性别机械配合。
5. 数词结构：**erbgħa** 独立读“四”，**erba’ snin** 表“四年”；**tliet kotba** 三本书，**ħdax-il ktieb** 十一本书，**għoxrin ktieb** 二十本书。
6. 双数作为整词记：**jumejn** 两天、**sagħtejn** 两小时、**ġimagħtejn** 两周、**xahrejn** 两个月、**sentejn** 两年、**darbtejn** 两次。
