# Maltese Module 3：逐页大纲与逐句逐词分析

**模块标题：Meta l-affarijiet ma jmorrux kif nixtiequ**  
**英文标题：When things go wrong**  
**中文译意：当事情不如我们所愿时**

## 模块标题解析

| 马耳他语 | 中文 | 逐词拆解 |
|---|---|---|
| Meta l-affarijiet ma jmorrux kif nixtiequ | 当事情不如我们所愿时 | **Meta** 当……时<br>**l-affarijiet** 事情、事物（冠词 l- + affarijiet；单数为 ħaġa）<br>**ma jmorrux** 它们不按某种方式发展、不顺利（ma … -x 构成否定；肯定形式为 jmorru，字面是“它们走”）<br>**kif** 如同、按照……的方式<br>**nixtiequ** 我们希望、我们想要（第一人称复数）。 |

英文标题 **When things go wrong** 可译为“当事情出岔子时”；马耳他语标题更贴近“当事情不如我们所愿时”。本模块通过遗失物品、迟到、事故及服务投诉等情景练习遇到问题时的表达。

## 整体大纲

| 页码 | 内容 |
|---|---|
| 1–2 | 两段日常对话：寻找遗失戒指、迟到求助；阅读理解题 |
| 3–5 | 口语情景表达、餐馆投诉评论、书面投诉信 |

### 阅读提示

- **il-/l-** 定冠词，类似英语 *the*；结合语境可译为“这/那”或不译。
- **fil-** 在……里（介词与冠词连写）。
- **tal-** ……的（介词与冠词连写）。
- **bil-** 用/带……（介词与冠词连写）。
- **plural sħiħ** 规则/完整复数，常见加词尾。
- **plural miksur** 破碎复数，词干内部也发生变化，不能只靠一个统一规则推出。

### 对话一：Brenda 找不到戒指

**Qari — Aqra dawn id-djalogi.**（阅读——读一读这些对话。）

| 马耳他语 | 中文 | 逐词拆解 |
|---|---|---|
| Xi ġralek, Brenda? | Brenda，你怎么了？ | **xi** 什么<br>**ġralek** 发生在你身上/你出了什么事（ġara + le-k）<br>**Brenda** 人名。 |
| Ħaw’, Anna, tlift iċ-ċurkett! | 嗨，Anna，我把戒指弄丢了！ | **Ħaw’** 嗨<br>**tlift** 我丢了<br>**iċ-ċurkett** 这枚戒指（冠词 + 戒指）。 |
| Fejn kont l-aħħar? | 你最后一次（记得）是在哪里？ | **fejn** 哪里<br>**kont** 你曾经在/你当时在<br>**l-aħħar** 最后、上一次。 |
| Ilni ġurnata ndur il-ħwienet! | 我逛商店已经逛了一整天！ | **ilni** 我已经……这么久<br>**ġurnata** 一天<br>**ndur** 我四处转/逛<br>**il-ħwienet** 这些商店（复数）。 |
| Ma nafx meta kien l-aħħar f’subgħi! | 我不知道它最后一次在我手指上是什么时候！ | **ma … x** 否定框架<br>**nafx** 我不知道<br>**meta** 什么时候<br>**kien** 是/在（过去）<br>**l-aħħar** 最后一次<br>**f’** 在……上/里<br>**subgħi** 我的手指。 |
| Ikkalma. Prova aħseb ftit. | 冷静点，试着想一想。 | **ikkalma** 冷静下来（命令式）<br>**prova** 试试<br>**aħseb** 想<br>**ftit** 一点儿。 |
| Iva! Sakemm xtrajt il-libsa kien għadu f’subgħajja għax jien u nipprovaha weħilli magħha. | 对！我买那条裙子时它还在我手指上，因为我试穿时它勾在裙子上了。 | **iva** 对<br>**sakemm** 到……时/当……时<br>**xtrajt** 我买了<br>**il-libsa** 这条裙子<br>**kien għadu** 仍然是/还在<br>**f’** 在<br>**subgħajja** 我的手指上<br>**għax** 因为<br>**jien u nipprovaha** 我在试穿它的时候<br>**weħilli** 它粘住/挂住了我<br>**magħha** 在它上面/和它一起（指裙子）。 |
| Mela ejja mmorru f’dak il-ħanut, forsi waqagħlek hemm. | 那我们去那家店吧，也许它在那里掉了。 | **mela** 那么<br>**ejja** 来吧<br>**mmorru** 我们去<br>**f’dak** 在那一个<br>**il-ħanut** 商店<br>**forsi** 也许<br>**waqagħlek** 它从你身上掉了<br>**hemm** 那里。 |
| Nispera li jekk sabu xi ħadd, ma baqax sejjer bih! | 我希望如果有人捡到了，他没有把它带走！ | **nispera** 我希望<br>**li** ……<br>**jekk** 如果<br>**sabu** 他们/有人找到了<br>**xi ħadd** 某个人<br>**ma … x** 否定<br>**baqax** 没有继续/没有留下<br>**sejjer** 走<br>**bih** 带着它。 |

### 对话二：Emily 错过公交车

关于迟到和等下一班车的句子已按你校正后的转录稿补全。

| 马耳他语 | 中文 | 逐词拆解 |
|---|---|---|
| Ħelow, is-Sur Caruana? | 喂，请问是 Caruana 先生吗？ | **Ħelow** 喂/您好<br>**is-Sur** 先生<br>**Caruana** 姓氏。 |
| Iva, jien hu, għidli. | 是我，请说。 | **iva** 是<br>**jien** 我<br>**hu** 他/就是本人（此处指接电话的人）<br>**għidli** 告诉我/请说。 |
| Sur Caruana, jien Emily. Skużani imma ħa nasal tard għax-xogħol għax tlift tal-linja bl-eżatt! | Caruana 先生，我是 Emily。对不起，我上班要迟到了，因为我刚好错过了公交车！ | **Sur Caruana** Caruana 先生<br>**jien** 我（这里省略“是”）<br>**Emily** 人名<br>**Skużani** 请原谅我、对不起<br>**imma** 但是<br>**ħa nasal** 我将会到达（ħa 表将来，nasal 表“我到达”）<br>**tard** 晚、迟<br>**għax-xogħol** 去上班、到工作地点（għal + 冠词 + xogħol 的连写形式；这里不是“因为”）<br>**għax** 因为<br>**tlift** 我错过了<br>**tal-linja** 公交车（此处省略 karozza，完整表达为 karozza tal-linja）<br>**bl-eżatt** 正好、恰恰。 |
| Issa fadal nofs siegħa oħra sabiex tgħaddi oħra. | 现在还要再等半小时，才会有另一班公交车经过。 | **Issa** 现在<br>**fadal** 还剩、还需要（时间）<br>**nofs siegħa** 半小时（nofs：一半；siegħa：小时）<br>**oħra** 再一个、另外的（修饰 siegħa；nofs siegħa oħra 合起来指“再半小时”）<br>**sabiex** 为了、以便；此处结合等车语境译为“才会……”<br>**tgħaddi** 它经过（第三人称阴性单数，指公交车）<br>**oħra** 另一辆、另一班（阴性单数，省略了指公交车的名词）。 |
| Żgur ma tistax tagħmel mod ieħor? Forsi jista’ jwasslek xi ħadd? | 你肯定不能想别的办法吗？也许有人能送你？ | **żgur** 肯定<br>**ma tistax** 你不能<br>**tagħmel** 做<br>**mod ieħor** 另一种办法<br>**forsi** 也许<br>**jista’** 能<br>**jwasslek** 把你送到<br>**xi ħadd** 某个人。 |
| Ħadd ma jista’ jwassalni bħalissa għax il-papà għandu l-karozza bil-ħsara. | 现在没人能送我，因为爸爸的车坏了。 | **ħadd** 没有人<br>**ma jista’** 不能<br>**jwassalni** 把我送到<br>**bħalissa** 现在、此刻<br>**għax** 因为<br>**il-papà** 爸爸<br>**għandu** 他有<br>**il-karozza** 汽车<br>**bil-ħsara** 有损坏/坏了。 |
| Jekk naqbad taxi tiġini ftit għolja. | 如果我打车，会贵一点。 | **jekk** 如果<br>**naqbad** 我乘/我搭<br>**taxi** 出租车<br>**tiġini** 对我来说会变得/会花<br>**ftit** 有点<br>**għolja** 贵（字面“高”）。 |
| Inti fejn qiegħda? | 你在哪里？（对女性说） | **inti** 你<br>**fejn** 哪里<br>**qiegħda** 位于/待着（阴性形式）。 |
| Ħa nara jekk il-ħaddiema humiex qrib tiegħek bil-vann tax-xogħol. Fil-każ jgħaddu għalik huma. | 我看看工人们是否在你附近、开着工作用的货车；如果可以，他们会顺路来接你。 | **ħa nara** 我来看看<br>**jekk** 是否<br>**il-ħaddiema** 工人们<br>**humiex** 是否是/是否在<br>**qrib** 附近<br>**tiegħek** 你的<br>**bil-vann** 开着/乘坐货车<br>**tax-xogħol** 工作用的<br>**fil-każ** 如果是这样<br>**jgħaddu** 他们经过/顺路<br>**għalik** 为你<br>**huma** 他们。 |
| Jien qiegħda ż-Żurrieq, fil-pjazza. | 我在 Żurrieq 的广场。 | **jien** 我<br>**qiegħda** 位于（女性说话者）<br>**ż-Żurrieq** 地名 Żurrieq<br>**fil-pjazza** 在广场上。 |
| Ok, se niċċekkja u nerġa’ nċempillek. | 好，我查一下再给你回电话。 | **se** 将要<br>**niċċekkja** 我检查<br>**u** 和<br>**nerġa’** 我再/重新<br>**nċempillek** 我打电话给你。 |
| Illaħwa, kieku tajjeb! Grazzi, Sur Caruana, u skużani mill-ġdid. | 哎呀，那就太好了！谢谢你，Caruana 先生，再次向你道歉。 | **illaħwa** 哎呀/天哪（感叹）<br>**kieku** 那样的话<br>**tajjeb** 好<br>**grazzi** 谢谢<br>**u** 和<br>**skużani** 原谅我<br>**mill-ġdid** 再一次。 |

## 第 4 页：情景对话与餐馆评论

**Agħżel xenarju minn dawn it-tlieta u pprepara djalogu li ser tippreżenta quddiem sħabek.**

从三个情景中选一个，准备一段要在同学面前表演的对话。

- **agħżel** 选择
- **xenarju** 情景
- **minn** 从
- **dawn it-tlieta** 这三个
- **u** 并
- **pprepara** 准备
- **djalogu** 对话
- **li ser** 将要……的
- **tippreżenta** 你展示
- **quddiem** 在……面前
- **sħabek** 你的同伴/同学。

**Il-Qari — Aqra dan l-ilment u l-kummenti daqslikieku rajthom fuq il-midja soċjali.**

阅读这则投诉和评论，假装你是在社交媒体上看到它们。

- **aqra** 读
- **dan l-ilment** 这则投诉
- **u** 和
- **il-kummenti** 评论
- **daqslikieku** 仿佛
- **rajthom** 你看到了它们
- **fuq** 在……上
- **il-midja soċjali** 社交媒体。

### Rachel 的评论

> **Ma nirrakkomandax ir-ristorant “Bella Malta” li jinsab Marsaxlokk minħabba s-servizz ħażin li rċivejna!**
>
> 我不推荐位于 Marsaxlokk 的 “Bella Malta” 餐厅，因为我们得到的服务很差！
>
> - **ma nirrakkomandax** 我不推荐
> - **ir-ristorant** 餐厅
> - **li** ……的
> - **jinsab** 位于
> - **minħabba** 因为
> - **is-servizz** 服务

## 复习重点

1. **询问与解释情况：**  
	*X’ġralek?*（你怎么了？）  
	*Ma nafx*（我不知道）  
	*Skużani*（对不起/请原谅我）。
2. **请求帮助与服务：**  
	*Xi ħadd jista’ jgħinni?*（有人能帮我吗？）  
	*Nixtieq inkellem lill-maniġer*（我想找经理谈谈）。
3. **表达位置：**  
	*fuq* 上  
	*taħt* 下  
	*quddiem* 前  
	*wara* 后  
	*bejn* 之间  
	*ħdejn/maġenb* 旁边。
4. **名词复数：** 规则复数和破碎复数都需要结合词例记忆；不要假设所有词都只加同一个后缀。
