# 马耳他语练习文档要求

本套资料用于马耳他语初学者练习。每篇先完整列出马耳他语短文；短文中的人名使用英语或马耳他语拼写；随后逐句翻译，并逐词说明。每项内容单独保存为 Markdown 文件，另设一个文件作为目录。

## 情景对话

1. 两人对话：预约医院的时间。
2. 两人对话：失物招领，并预约到警局领取失物的时间。
3. 两人对话：参加周末派对。
4. 两人对话：询问当前时间。
5. 两人对话：闲聊今天、明天、本周末、下周、下个月和明年的计划。

## 邮件

6. 邀请参加生日派对。
7. 回复生日派对邀请。
8. 邀请参加婚礼。
9. 回复婚礼邀请。
10. 邀请参加晚餐。
11. 回复晚餐邀请。

## 文档与格式

- 本要求说明作为第一篇 Markdown 文档。
- 邮件分类编号按列出顺序从 `01` 递增；新增邮件主题接在原有邮件之后。
- 情景对话和邮件分别放入独立文件夹：`dialogues/` 与 `emails/`。
- 每个对话或邮件主题各自使用一个 Markdown 文件，并在所属分类中按原始列出顺序从 `01` 开始编号。
- 根目录提供总目录；`dialogues/` 和 `emails/` 中也各自提供一个分类目录页。
- 每篇短文先完整呈现，再提供逐句中文翻译和逐词拆解。
- 短文中的人名使用英语或马耳他语拼写。
