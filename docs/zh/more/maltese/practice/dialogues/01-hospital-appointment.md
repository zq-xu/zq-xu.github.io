# 预约医院就诊时间

**场景：** David 打电话到健康中心，向接待员 Maria 预约医生并确认时间和证件。

## 完整对话

**Maria：** Bonġu, Ċentru tas-Saħħa. Kif nista' ngħinek?

**David：** Bonġu. Nixtieq nagħmel appuntament mat-tabib, jekk jogħġbok.

**Maria：** Għandek preferenza għal xi ġurnata?

**David：** Jekk jista' jkun, għada filgħodu.

**Maria：** Għandna ħin fl-għaxra u nofs. Tajjeb għalik?

**David：** Iva, tajjeb ħafna. Għandi bżonn inġib xi dokumenti?

**Maria：** Ġib il-karta tal-identità u l-karta tas-saħħa.

**David：** Grazzi. Narak għada.

## 逐句翻译与逐词拆解

### 1. Maria（接待员）

**Malti:** Bonġu, Ċentru tas-Saħħa. Kif nista' ngħinek?

**整句：** 早上好，这里是健康中心。我可以怎样帮您？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Bonġu | 你好；早上好 | 常见问候语 |
| Ċentru | 中心 | 阳性名词 |
| tas-Saħħa | 健康的 | `ta' + is-saħħa` 的缩合形式，意为“健康中心的” |
| Kif | 怎样；如何 | 疑问词 |
| nista' | 我可以 | `n-` 第一人称标记；`jista'` 表示“能够” |
| ngħinek | 帮助您/你 | `ngħin`“我帮助” + `-ek`“你” |

### 2. David（病人）

**Malti:** Bonġu. Nixtieq nagħmel appuntament mat-tabib, jekk jogħġbok.

**整句：** 早上好。我想预约看医生，麻烦您。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Bonġu | 你好；早上好 | 问候语 |
| Nixtieq | 我想要 | 礼貌表达愿望 |
| nagħmel | 我做；我安排 | `nagħmel appuntament` 表示“预约” |
| appuntament | 预约；约会 | 阳性名词，借词 |
| mat-tabib | 和/与医生；看医生 | `ma'`“和” + 定冠词 `it-`，发生拼写缩合 |
| jekk | 如果 | 常与 `jogħġbok` 构成礼貌用语 |
| jogħġbok | 请；使您高兴 | `jekk jogħġbok` 整体相当于“请/麻烦您” |

### 3. Maria（接待员）

**Malti:** Għandek preferenza għal xi ġurnata?

**整句：** 您比较希望哪一天？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandek | 你有；您有 | `għand` 的第二人称单数形式 |
| preferenza | 偏好；选择 | 阴性名词 |
| għal | 对于；关于 | 介词 |
| xi | 某个；任何 | 这里用于询问“哪一天” |
| ġurnata | 一天；日子 | 阴性名词 |

### 4. David（病人）

**Malti:** Jekk jista' jkun, għada filgħodu.

**整句：** 如果可以的话，明天早上。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jekk | 如果 | 连词 |
| jista' | 可以；可能 | 第三人称阳性单数形式 |
| jkun | 是；成为 | `ikun` 的虚拟/从属形式，见于固定表达 `jekk jista' jkun` |
| għada | 明天 | 时间副词 |
| filgħodu | 在早上 | 时间表达；源自“早晨”一类形式 |

### 5. Maria（接待员）

**Malti:** Għandna ħin fl-għaxra u nofs. Tajjeb għalik?

**整句：** 我们十点半有空。这个时间对您合适吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandna | 我们有 | `għand` 的第一人称复数形式 |
| ħin | 时间；空闲时间 | 阳性名词 |
| fl-għaxra | 在十点 | `f'`“在” + `l-għaxra`“十点”的缩合形式 |
| u | 和；过 | 此处连接整点与“半” |
| nofs | 一半；半 | 时间表达中表示半点 |
| Tajjeb | 好；合适 | 阳性形式；此处指时间合适 |
| għalik | 对你；对您 | `għal`“对” + `-ik`“你” |

### 6. David（病人）

**Malti:** Iva, tajjeb ħafna. Għandi bżonn inġib xi dokumenti?

**整句：** 是的，非常合适。我需要带什么文件吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Iva | 是；对 | 肯定回答 |
| tajjeb | 好；合适 | 阳性形式 |
| ħafna | 很；非常；许多 | 此处修饰 `tajjeb`，表示“非常” |
| Għandi | 我有 | `għand` 的第一人称单数形式 |
| bżonn | 需要 | `għandi bżonn` 整体表示“我需要” |
| inġib | 我带来；我拿来 | 第一人称单数形式 |
| xi | 一些；什么 | 疑问句中可表示“什么” |
| dokumenti | 文件；证件 | `dokument` 的复数 |

### 7. Maria（接待员）

**Malti:** Ġib il-karta tal-identità u l-karta tas-saħħa.

**整句：** 请带上身份证和健康卡。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Ġib | 带来；拿来 | 对一人的命令式 |
| il-karta | 卡；纸张 | `il-` 定冠词 + `karta` |
| tal-identità | 身份的 | `ta' + l-identità` 的缩合形式 |
| u | 和 | 连词 |
| il-karta | 卡 | 阴性名词，带定冠词 |
| tas-saħħa | 健康的 | `ta' + is-saħħa` 的缩合形式 |

### 8. David（病人）

**Malti:** Grazzi. Narak għada.

**整句：** 谢谢。明天见。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi | 谢谢 | 常用礼貌用语 |
| Narak | 我见到你；再见 | `nara`“我看见” + `-k`“你” |
| għada | 明天 | 时间副词 |

## 可替换表达

- `filgħodu`：早上；`wara nofsinhar`：下午；`filgħaxija`：晚上。
- `Għandi appuntament.`：我有预约。
- `Nista' nbiddel il-ħin?`：我可以改时间吗？
