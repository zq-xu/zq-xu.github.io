# 失物招领与警局领取

**场景：** Mark 在警局接听失主 Anna 的电话，两人确认钱包并约定领取时间。

## 完整对话

**Anna：** Bonġu. Sibtu kartiera mitlufa ħdejn il-waqfa tal-karozzi tal-linja?

**Mark：** Iva, il-kartiera tinsab hawn fl-għassa tal-pulizija.

**Anna：** X'nagħmel biex niġi niġborha?

**Mark：** Tista' tiġi l-għassa għada filgħodu.

**Anna：** Nista' niġi fid-disgħa?

**Mark：** Iva. Ġib miegħek dokument ta' identità.

**Anna：** Se jkolli bżonn inġib xi prova oħra?

**Mark：** Le, id-dokument tal-identità jkun biżżejjed.

## 逐句翻译与逐词拆解

### 1. Anna（失主）

**Malti:** Bonġu. Sibtu kartiera mitlufa ħdejn il-waqfa tal-karozzi tal-linja?

**整句：** 你好。您是否在公交车站附近捡到一个丢失的钱包？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Bonġu | 你好 | 问候语 |
| Sibtu | 您找到/捡到了吗 | `sibt`“我/你找到”依语境解释；`-u` 可指代阳性物件，这里相当于“它” |
| kartiera | 钱包 | 阴性名词 |
| mitlufa | 丢失的 | 阴性单数形式，与 `kartiera` 一致 |
| ħdejn | 在……旁边；附近 | 位置介词 |
| il-waqfa | 车站；停靠点 | 阴性名词，带定冠词 |
| tal-karozzi | 汽车的 | `ta'` 与定冠词缩合；`karozzi` 为复数 |
| tal-linja | 线路的 | `ta' + il-linja` 的缩合形式，`karozzi tal-linja` 指公交车 |

### 2. Mark（警局工作人员）

**Malti:** Iva, il-kartiera tinsab hawn fl-għassa tal-pulizija.

**整句：** 是的，钱包在这里的警察局。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Iva | 是的 | 肯定回答 |
| il-kartiera | 钱包 | `il-` 定冠词 + `kartiera` |
| tinsab | 位于；在 | 阴性主语所用形式 |
| hawn | 这里 | 地点副词 |
| fl-għassa | 在警局 | `f'`“在” + `l-għassa` 的缩合形式 |
| tal-pulizija | 警察的 | `ta' + il-pulizija` 的缩合形式 |

### 3. Anna（失主）

**Malti:** X'nagħmel biex niġi niġborha?

**整句：** 我该怎么做才能来把它领走？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| X' | 什么；怎样 | `x'` 是 `xiex` 的缩写形式 |
| nagħmel | 我做 | 第一人称单数形式 |
| biex | 为了；以便 | 引出目的或后续动作 |
| niġi | 我来 | 第一人称单数形式 |
| niġborha | 我把它领走/取回 | `niġbor`“我收集/领取” + `-ha`“它（阴性）” |

### 4. Mark（警局工作人员）

**Malti:** Tista' tiġi l-għassa għada filgħodu.

**整句：** 您明天早上可以来警局。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tista' | 你可以；您可以 | 第二人称单数形式 |
| tiġi | 来 | 与 `tista'` 连用，表示可以来 |
| l-għassa | 警局；警察岗亭 | 阴性名词，带定冠词 |
| għada | 明天 | 时间副词 |
| filgħodu | 在早上 | 时间表达 |

### 5. Anna（失主）

**Malti:** Nista' niġi fid-disgħa?

**整句：** 我可以九点来吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nista' | 我可以吗 | 第一人称单数形式 |
| niġi | 我来 | 第一人称单数形式 |
| fid-disgħa | 在九点 | `f'`“在” + `id-disgħa`“九点”的缩合形式 |

### 6. Mark（警局工作人员）

**Malti:** Iva. Ġib miegħek dokument ta' identità.

**整句：** 可以。请随身带上身份证件。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Iva | 是；可以 | 肯定回答 |
| Ġib | 带来；拿来 | 对一人的命令式 |
| miegħek | 和你一起；随身 | `miegħ`“和” + `-ek`“你” |
| dokument | 文件；证件 | 阳性名词 |
| ta' | ……的 | 连接名词，表示所属或类别 |
| identità | 身份 | 阴性名词 |

### 7. Anna（失主）

**Malti:** Se jkolli bżonn inġib xi prova oħra?

**整句：** 我还需要带其他证明吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Se | 将；会 | 常用将来标记 |
| jkolli | 我将有；我需要 | `għandi` 的将来形式之一 |
| bżonn | 需要 | `ikolli bżonn` 表示“我需要” |
| inġib | 我带来 | 第一人称单数形式 |
| xi | 一些；任何 | 此处表示“其他的/任何” |
| prova | 证明；证据 | 阴性名词 |
| oħra | 其他的 | 阴性形式，与 `prova` 一致 |

### 8. Mark（警局工作人员）

**Malti:** Le, id-dokument tal-identità jkun biżżejjed.

**整句：** 不用，身份证件就足够了。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Le | 不；不用 | 否定回答 |
| id-dokument | 文件；证件 | 定冠词与名词连写 |
| tal-identità | 身份的 | `ta' + l-identità` 的缩合形式 |
| jkun | 会是；足以 | `ikun` 的从属/虚拟形式 |
| biżżejjed | 足够 | 固定形容词/副词表达 |

## 词汇补充

- `uffiċċju tal-pulizija`：警察局办公室。
- `rapport`：报告；报案记录。
- `Tlift il-kartiera tiegħi.`：我把钱包弄丢了。
- 领取失物时，实际手续可能因警局和物品类型而异；对话用于语言练习。
