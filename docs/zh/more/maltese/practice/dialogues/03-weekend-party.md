# 参加周末派对

**场景：** 两位朋友商量参加周末派对的安排。

## 完整对话

**Anna：** Se tagħmel xi ħaġa fi tmiem il-ġimgħa?

**Mark：** Għadni ma ddeċidejtx. Għaliex?

**Anna：** Qed norganizza festa d-dar is-Sibt filgħaxija.

**Mark：** Ħsejjes sbieħ! F'liema ħin tibda?

**Anna：** Nibdew fit-tmienja, imma tista' tasal aktar tard.

**Mark：** X'għandi nġib miegħi?

**Anna：** Ġib xi ħaġa x'tixorbu u jien nagħmel l-ikel.

**Mark：** Perfett. Inkun hemm fit-tmienja.

## 逐句翻译与逐词拆解

### 1. Anna

**Malti:** Se tagħmel xi ħaġa fi tmiem il-ġimgħa?

**整句：** 你周末有什么安排吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Se | 将；会 | 这里与未完成式连用，询问计划 |
| tagħmel | 你做 | 第二人称单数形式 |
| xi | 某个；一些 | 用于询问是否有安排 |
| ħaġa | 事情 | 阴性名词 |
| fi | 在 | 介词，后接时间 |
| tmiem | 结束；末尾 | 阳性名词 |
| il-ġimgħa | 一周；星期 | `tmiem il-ġimgħa` 整体表示周末 |

### 2. Mark

**Malti:** Għadni ma ddeċidejtx. Għaliex?

**整句：** 我还没决定。怎么了？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għadni | 我仍然；我还 | `għad`“仍然” + `-ni` 第一人称后缀 |
| ma | 不 | 否定结构的一部分，常与句末 `x` 配合 |
| ddeċidejtx | 我没有决定 | 完成式否定形式；词尾 `-x` 标记否定 |
| Għaliex | 为什么 | 疑问词 |

### 3. Anna

**Malti:** Qed norganizza festa d-dar is-Sibt filgħaxija.

**整句：** 我正在组织星期六晚上在家举行的派对。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Qed | 正在 | 与动词未完成式一起构成进行表达 |
| norganizza | 我组织 | 第一人称单数形式 |
| festa | 派对；庆祝活动 | 阴性名词 |
| d-dar | 在家；家里 | `id-dar` 的常见缩合写法 |
| is-Sibt | 星期六 | 常带定冠词 |
| filgħaxija | 在晚上 | 时间表达 |

### 4. Mark

**Malti:** Ħsejjes sbieħ! F'liema ħin tibda?

**整句：** 听起来不错！几点开始？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Ħsejjes | 听起来 | 第三人称形式，字面关联“声音” |
| sbieħ | 好听的；不错的 | 阳性复数形式/固定搭配 |
| F'liema | 在什么 | `f'`“在” + `liema`“哪一个/什么” |
| ħin | 时间 | 阳性名词 |
| tibda | 你开始；它开始 | 形式可由主语决定，此处指派对开始 |

### 5. Anna

**Malti:** Nibdew fit-tmienja, imma tista' tasal aktar tard.

**整句：** 我们八点开始，不过你可以晚一点到。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nibdew | 我们开始 | 第一人称复数形式 |
| fit-tmienja | 在八点 | `f'` + 定冠词钟点形式的缩合 |
| imma | 但是；不过 | 连词 |
| tista' | 你可以 | 第二人称单数形式 |
| tasal | 你到达 | 第二人称单数形式 |
| aktar | 更；较 | 比较副词 |
| tard | 晚；迟 | 副词/形容词 |

### 6. Mark

**Malti:** X'għandi nġib miegħi?

**整句：** 我应该带些什么？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| X' | 什么 | 疑问词缩写 |
| għandi | 我有；我应该 | 此处和后面的动词一起表达“我该……” |
| nġib | 我带来 | 第一人称单数形式 |
| miegħi | 和我一起；随身 | `miegħ`“和” + `-i`“我” |

### 7. Anna

**Malti:** Ġib xi ħaġa x'tixorbu u jien nagħmel l-ikel.

**整句：** 带点喝的东西来，我来准备食物。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Ġib | 带来 | 对一人的命令式 |
| xi | 一些 | 不定限定词 |
| ħaġa | 东西 | 阴性名词 |
| x' | 可以……的；要……的 | 引出修饰前面名词的从句 |
| tixorbu | 你们喝；大家喝 | `tixorbu` 是复数形式；此处指来宾 |
| u | 和；而 | 连词 |
| jien | 我 | 强调代词 |
| nagħmel | 我做；我准备 | 第一人称单数形式 |
| l-ikel | 食物 | 定冠词 + `ikel` |

### 8. Mark

**Malti:** Perfett. Inkun hemm fit-tmienja.

**整句：** 太好了。我八点会到那里。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Perfett | 太好了；完美 | 阳性形式的形容词，也作感叹语 |
| Inkun | 我会是；我会在 | 第一人称单数形式 |
| hemm | 那里；在场 | 地点副词 |
| fit-tmienja | 在八点 | 时间表达 |

## 口语替换

- `il-Ġimgħa filgħaxija`：星期五晚上。
- `Nista' nġib deżerta?`：我可以带甜点吗？
- `Narawk is-Sibt.`：星期六见。
