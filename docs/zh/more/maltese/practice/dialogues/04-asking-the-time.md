# 询问当前时间

**场景：** 两位朋友在约好的地点碰面，一人询问时间并确认是否迟到。

## 完整对话

**Mark：** Skużani, x'ħin hu issa?

**Lina：** Huma t-tmienja u kwart.

**Mark：** Grazzi. Għandi appuntament fit-tmienja u nofs.

**Lina：** Għad għandek ħmistax-il minuta.

**Mark：** Tajjeb. Il-post jinsab ħdejn il-pjazza, hux?

**Lina：** Iva, eżattament. Jien qiegħda quddiem il-bieb.

**Mark：** Qed nitlaq issa. Nasal f'għaxar minuti.

**Lina：** Sewwa, narak dalwaqt.

## 逐句翻译与逐词拆解

### 1. Mark

**Malti:** Skużani, x'ħin hu issa?

**整句：** 不好意思，现在几点了？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Skużani | 不好意思；请原谅我 | 礼貌用语 |
| x'ħin | 几点；什么时间 | `x'`“什么” + `ħin`“时间” |
| hu | 是 | 第三人称阳性代词；此处对应“时间” |
| issa | 现在 | 时间副词 |

### 2. Lina

**Malti:** Huma t-tmienja u kwart.

**整句：** 现在是八点一刻。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Huma | 它们是；他们是 | 此处作系词形式引出时间 |
| it-tmienja | 八点 | 带定冠词的钟点形式 |
| u | 和；过 | 连接整点与分钟 |
| kwart | 一刻钟 | 时间名词，十五分钟 |

### 3. Mark

**Malti:** Grazzi. Għandi appuntament fit-tmienja u nofs.

**整句：** 谢谢。我八点半有约。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi | 谢谢 | 礼貌表达 |
| Għandi | 我有 | `għand` 的第一人称单数形式 |
| appuntament | 预约；约会 | 阳性名词 |
| fit-tmienja | 在八点 | `f'`“在” + 钟点形式缩合 |
| u | 和；过 | 连接时间部分 |
| nofs | 半 | `u nofs` 表示半点 |

### 4. Lina

**Malti:** Għad għandek ħmistax-il minuta.

**整句：** 你还有十五分钟。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għad | 仍然；还 | 表示状态持续 |
| għandek | 你有 | `għand` 的第二人称单数形式 |
| ħmistax-il | 十五 | 数字与后接名词的连接形式 |
| minuta | 分钟 | 阴性名词 |

### 5. Mark

**Malti:** Tajjeb. Il-post jinsab ħdejn il-pjazza, hux?

**整句：** 好的。地点在广场旁边，对吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tajjeb | 好；好的 | 阳性形式，也可作回应 |
| il-post | 地点；地方 | `il-` 定冠词 + `post` |
| jinsab | 位于；在 | 第三人称阳性单数形式 |
| ħdejn | 在……旁边 | 位置介词 |
| il-pjazza | 广场 | 阴性名词，带定冠词 |
| hux | 是吗；对吗 | 句末确认用语 |

### 6. Lina

**Malti:** Iva, eżattament. Jien qiegħda quddiem il-bieb.

**整句：** 对，正是如此。我在门前。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Iva | 是；对 | 肯定回答 |
| eżattament | 正是；准确地 | 副词 |
| Jien | 我 | 强调代词 |
| qiegħda | 位于；在 | 阴性说话者形式；男性说话者用 `qiegħed` |
| quddiem | 在……前面 | 位置介词 |
| il-bieb | 门 | 阳性名词，带定冠词 |

### 7. Mark

**Malti:** Qed nitlaq issa. Nasal f'għaxar minuti.

**整句：** 我现在出发。十分钟后到。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Qed | 正在 | 与动词一起表示正在进行 |
| nitlaq | 我离开；我出发 | 第一人称单数形式 |
| issa | 现在 | 时间副词 |
| Nasal | 我到达 | 第一人称单数形式 |
| f'għaxar | 在……之后；用……时间 | `f'` + `għaxar`“十” |
| minuti | 分钟 | `minuta` 的复数 |

### 8. Lina

**Malti:** Sewwa, narak dalwaqt.

**整句：** 好的，一会儿见。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Sewwa | 好；好的 | 常见回应 |
| narak | 我见到你；再见 | `nara`“我看见” + `-k`“你” |
| dalwaqt | 很快；不久 | 时间副词 |

## 时间表达提示

- `u kwart`：过一刻；`u nofs`：过半点。
- `neqsin kwart`：差一刻到下一点，例如 `id-disgħa neqsin kwart`（差一刻九点，8:45）。
- 需要避免歧义时，使用 24 小时制数字时间。
