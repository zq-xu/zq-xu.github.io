# 闲聊近期计划

**场景：** Anna 和 Mark 聊今天、明天、本周末、下周、下个月及明年的安排。

## 完整对话

**Anna：** X'għandek tagħmel illum u għada?

**Mark：** Illum naħdem mid-dar u filgħaxija nistudja l-Malti. Għada se mmur l-isptar ma' ommi.

**Anna：** X'se tagħmel fi tmiem il-ġimgħa?

**Mark：** Se niltaqa' mal-ħbieb għal kafè.

**Anna：** Għandek pjanijiet għall-ġimgħa d-dieħla?

**Mark：** Iva. Nhar it-Tlieta se nżur lill-familja tiegħi.

**Anna：** U x-xahar id-dieħel?

**Mark：** Se nivvjaġġa lejn Għawdex għal ftit jiem.

**Anna：** X'tixtieq tagħmel is-sena d-dieħla?

**Mark：** Nixtieq nitgħallem aktar il-Malti u nsiefer.

## 逐句翻译与逐词拆解

### 1. Anna

**Malti:** X'għandek tagħmel illum u għada?

**整句：** 你今天和明天要做什么？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| X' | 什么 | `xiex` 的缩略形式，常连写在后续词前 |
| għandek | 你有；你需要 | `għand` 的第二人称单数形式 |
| tagħmel | 你做 | 第二人称单数形式 |
| illum | 今天 | 时间副词 |
| u | 和 | 连词 |
| għada | 明天 | 时间副词 |

### 2. Mark

**Malti:** Illum naħdem mid-dar u filgħaxija nistudja l-Malti.

**整句：** 今天我在家工作，晚上学习马耳他语。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Illum | 今天 | 时间副词 |
| naħdem | 我工作 | 第一人称单数形式 |
| mid-dar | 从家里；在家 | `minn`“从” + `id-dar`“家”的缩合形式 |
| u | 和；并且 | 连词 |
| filgħaxija | 在晚上 | 时间表达 |
| nistudja | 我学习 | 第一人称单数形式 |
| l-Malti | 马耳他语 | 语言名称，带定冠词 |

### 3. Mark

**Malti:** Għada se mmur l-isptar ma' ommi.

**整句：** 明天我会和妈妈去医院。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għada | 明天 | 时间副词 |
| se | 将；会 | 常用将来标记 |
| mmur | 我去 | 第一人称单数形式 |
| l-isptar | 医院 | `l-` 定冠词 + `isptar` |
| ma' | 和；与 | 介词 |
| ommi | 我的妈妈 | `omm`“母亲” + 第一人称所有格后缀 `-i` |

### 4. Anna

**Malti:** X'se tagħmel fi tmiem il-ġimgħa?

**整句：** 你本周末打算做什么？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| X' | 什么 | 疑问词缩略形式 |
| se | 将；会 | 将来标记 |
| tagħmel | 你做 | 第二人称单数形式 |
| fi | 在 | 介词 |
| tmiem | 结束；末尾 | 与后文组成时间短语 |
| il-ġimgħa | 一周；星期 | `tmiem il-ġimgħa` 整体表示“周末” |

### 5. Mark

**Malti:** Se niltaqa' mal-ħbieb għal kafè.

**整句：** 我会和朋友们见面喝咖啡。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Se | 将；会 | 将来标记 |
| niltaqa' | 我见面 | 第一人称单数形式；词尾撇号是拼写的一部分 |
| mal-ħbieb | 和朋友们 | `ma'`“和” + `il-ħbieb`“朋友们”的缩合形式 |
| għal | 为了；去做 | 此处表示目的 |
| kafè | 咖啡 | 阳性名词；此处指喝咖啡 |

### 6. Anna

**Malti:** Għandek pjanijiet għall-ġimgħa d-dieħla?

**整句：** 你下周有什么计划吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandek | 你有 | `għand` 的第二人称单数形式 |
| pjanijiet | 计划 | `pjan` 的复数 |
| għall-ġimgħa | 为下周；对于这一周 | `għal` + `il-ġimgħa` 的缩合形式 |
| d-dieħla | 接下来的；下一个 | 阴性形式，与 `ġimgħa` 一致 |

### 7. Mark

**Malti:** Iva. Nhar it-Tlieta se nżur lill-familja tiegħi.

**整句：** 是的。星期二我会去看望我的家人。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Iva | 是；对 | 肯定回答 |
| Nhar | 在……那天 | 引出星期或日期 |
| it-Tlieta | 星期二 | 星期名称通常带定冠词 |
| se | 将；会 | 将来标记 |
| nżur | 我拜访；我看望 | 第一人称单数形式 |
| lill-familja | 家人；我的家人（作宾语） | 人称宾语标记 `lil` 与定冠词连写 |
| tiegħi | 我的 | 所有格代词 |

### 8. Anna

**Malti:** U x-xahar id-dieħel?

**整句：** 那下个月呢？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| U | 和；那么 | 连接上文，也可引出追问 |
| x-xahar | 月；这个月 | `xahar`“月”的定冠词形式 |
| id-dieħel | 下一个；即将到来的 | 阳性形式，与 `xahar` 一致 |

### 9. Mark

**Malti:** Se nivvjaġġa lejn Għawdex għal ftit jiem.

**整句：** 我下个月会去戈佐岛旅行几天。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Se | 将；会 | 将来标记；承接上句的下个月 |
| nivvjaġġa | 我旅行 | 第一人称单数形式 |
| lejn | 朝向；到 | 方向介词 |
| Għawdex | 戈佐岛 | 马耳他群岛中的岛名 |
| għal | 持续；为期 | 此处引出时长 |
| ftit | 几；少量 | 数量词 |
| jiem | 天 | `jum`“天”的复数形式 |

### 10. Anna

**Malti:** X'tixtieq tagħmel is-sena d-dieħla?

**整句：** 你明年想做什么？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| X' | 什么 | 疑问词缩略形式 |
| tixtieq | 你想要；你希望 | 第二人称单数形式，常用于礼貌询问 |
| tagħmel | 你做 | 第二人称单数形式 |
| is-sena | 年 | `sena`“年”的定冠词形式 |
| d-dieħla | 下一个；来临的 | 阴性形式，与 `sena` 一致 |

### 11. Mark

**Malti:** Nixtieq nitgħallem aktar il-Malti u nsiefer.

**整句：** 我想多学一些马耳他语，也想出国旅行。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nixtieq | 我想要；我希望 | 第一人称单数形式 |
| nitgħallem | 我学习 | 第一人称单数形式，词中有 `għ` |
| aktar | 更多；进一步 | 程度副词 |
| il-Malti | 马耳他语 | 语言名称 |
| u | 和；并且 | 连词 |
| nsiefer | 我出国旅行 | 第一人称单数形式 |

## 时间短语速记

- `illum`：今天
- `għada`：明天
- `fi tmiem il-ġimgħa`：本周末
- `il-ġimgħa d-dieħla`：下周
- `ix-xahar id-dieħel`：下个月
- `is-sena d-dieħla`：明年
