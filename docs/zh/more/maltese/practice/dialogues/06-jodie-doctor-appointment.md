# 预约 Farrugia 医生

**场景：** Jodie 打电话到诊所，预约 Farrugia 医生下周就诊，双方商定周四晚上七点。（说话人标签根据对话语境推断，原文为听力练习。）

## 完整对话

**Jodie（患者）：** Nista' nagħmel appuntament għall-ġimgħa d-dieħla mat-tabib Farrugia?

**接待员：** Il-ġimgħa d-dieħla għandi vojt l-Erbgħa u l-Ħamis.

**Jodie（患者）：** L-Erbgħa ma nistax, imma l-Ħamis iva. Fi x'hin?

**接待员：** Filgħodu?

**接待员：** Jew filgħaxija?

**Jodie（患者）：** Filgħaxija aħjar, wara x-xogħol.

**接待员：** Fis-6, fis-6:30, jew fis-7pm?

**Jodie（患者）：** Fis-sebgħa tajjeb, grazzi!

**接待员：** Ibbukkajt il-Ħamis fis-sebgħa ta' filgħaxija.

**接待员：** Nikkonferma, saħħa.

## 逐句翻译与逐词拆解

### 1. Jodie（患者）

**Malti:** Nista' nagħmel appuntament għall-ġimgħa d-dieħla mat-tabib Farrugia?

**整句：** 我能不能约下周和 Farrugia 医生见面？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nista' | 我能 | 第一人称单数 |
| nagħmel | 我做；我约 | 第一人称单数现在时 |
| appuntament | 预约；约见 | 阳性名词，借词 appointment |
| għall-ġimgħa | 为下周 | `għal`+`il-ġimgħa` 缩合 |
| d-dieħla | 即将到来的 | `id-dieħla`，dieħel 阴性单数带定冠词 |
| mat-tabib | 和医生 | `ma'`+`it-tabib` 缩合 |
| Farrugia | Farrugia | 医生姓氏 |

### 2. 接待员

**Malti:** Il-ġimgħa d-dieħla għandi vojt l-Erbgħa u l-Ħamis.

**整句：** 下周我周三和周四有空。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Il-ġimgħa | 星期 | 阴性名词，带定冠词 |
| d-dieħla | 即将到来的 | 修饰 il-ġimgħa |
| għandi | 我有 | `għand` 第一人称单数 |
| vojt | 空；空闲 | 名词 |
| l-Erbgħa | 周三 | 带定冠词的星期名 |
| u | 和 | 连词 |
| l-Ħamis | 周四 | 带定冠词的星期名 |

### 3. Jodie（患者）

**Malti:** L-Erbgħa ma nistax, imma l-Ħamis iva. Fi x'hin?

**整句：** 周三不行，但周四可以。几点？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| L-Erbgħa | 周三 | 带定冠词 |
| ma nistax | 我不能 | `ma`+`nista'`+`x` 构成否定 |
| imma | 但是 | 转折连词 |
| l-Ħamis | 周四 | 带定冠词 |
| iva | 是的；可以 | 肯定应答 |
| Fi | 在…… | 介词 `f'` 的变体 |
| x'hin | 什么时间 | `x'`（什么）+ hin（时间） |

### 4. 接待员

**Malti:** Filgħodu?

**整句：** 上午？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Filgħodu | 在上午 | `f'`+`il-għodu` 缩合；原文拼写 `flgħodu` 应为 `filgħodu` |

### 5. 接待员

**Malti:** Jew filgħaxija?

**整句：** 还是晚上？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jew | 或者 | 连词 |
| filgħaxija | 在晚上 | `f'`+`il-għaxija` 缩合 |

### 6. Jodie（患者）

**Malti:** Filgħaxija aħjar, wara x-xogħol.

**整句：** 晚上更好，下班后。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Filgħaxija | 在晚上 | 时间表达 |
| aħjar | 更好 | `tajjeb` 的比较级 |
| wara | 之后 | 介词 |
| x-xogħol | 工作 | 阳性名词，带定冠词 |

### 7. 接待员

**Malti:** Fis-6, fis-6:30, jew fis-7pm?

**整句：** 6 点、6:30 还是晚上 7 点？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Fis-6 | 在 6 点 | `f'`+`is-`（数字定冠词形式） |
| jew | 还是 | 选择连词 |
| fis-7pm | 在晚上 7 点 | pm 表示晚间 |

### 8. Jodie（患者）

**Malti:** Fis-sebgħa tajjeb, grazzi!

**整句：** 7 点可以，谢谢！

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Fis-sebgħa | 在 7 点 | `f'`+`is-sebgħa` |
| tajjeb | 好的；可以 | 形容词 |
| grazzi | 谢谢 | 礼貌用语 |

### 9. 接待员

**Malti:** Ibbukkajt il-Ħamis fis-sebgħa ta' filgħaxija.

**整句：** 我订了周四晚上 7 点。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Ibbukkajt | 我预订了 | 借词 book，第一人称单数过去时 |
| il-Ħamis | 周四 | 带定冠词 |
| fis-sebgħa | 在 7 点 | 时间表达 |
| ta' filgħaxija | 晚上的 | `ta'`+`filgħaxija` |

### 10. 接待员

**Malti:** Nikkonferma, saħħa.

**整句：** 确认，再见。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nikkonferma | 我确认 | 借词 confirm |
| saħħa | 保重；再见 | 字面"健康"，常用告别语 |
