# 餐厅晚餐——短信对话

**场景：** Claire 和朋友互发短信，确认今晚在餐厅晚餐的安排：见面时间、着装和孩子照看。（说话人标签根据对话语境推断。）

## 完整对话

**朋友：** Waranofsinhar it-tajjeb, Claire. Għal illejla kollox sew?

**Claire：** Waranofsinhar it-tajjeb. Iva għal-lejla kollox sew. Fit-tmienja u nofs hux?

**朋友：** Eżatt, niltaqgħu fit-tmienja u nofs u nidħlu ġewwa l-ħanut.

**朋友：** X'ser tilbes?

**朋友：** Ħa tilbes ġakketta?

**Claire：** Qed ikun ftit bard u għalhekk naħseb nilbes ġakketta u flokk tas-suf.

**朋友：** Tajjeb, nilbes bħalek mela. It-tifel se iġġibuh magħkom?

**Claire：** Jien u r-raġel, it-tifel ser inħalluh m'ommi.

**朋友：** Tajjeb, niltaqgħu mela. Saħħiet.

**Claire：** Iva, niltaqgħu. Saħħiet.

## 逐句翻译与逐词拆解

### 1. 朋友

**Malti:** Waranofsinhar it-tajjeb, Claire. Għal illejla kollox sew?

**整句：** 下午好，Claire。今晚一切都好吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Waranofsinhar | 下午 | `wara`（之后）+ `nofsinhar`（正午） |
| it-tajjeb | 好的 | `tajjeb` 带定冠词，问候语"下午好" |
| Għal | 对于 | 介词 |
| illejla | 今晚 | `il-lejla` |
| kollox | 一切 | 不定代词 |
| sew | 好；顺利 | 副词 |

### 2. Claire

**Malti:** Waranofsinhar it-tajjeb. Iva għal-lejla kollox sew. Fit-tmienja u nofs hux?

**整句：** 下午好。是的，今晚一切都好。八点半，对吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Waranofsinhar it-tajjeb | 下午好 | 问候语 |
| Iva | 是的 | 肯定应答 |
| għal-lejla | 今晚 | `għal`+`il-lejla` |
| kollox sew | 一切都好 | 固定搭配 |
| Fit-tmienja | 在八点 | `f'`+`it-tmienja` |
| u nofs | 半 | 时间表达"八点半" |
| hux | 对吧；是吗 | `hu`+`x` 疑问小词，求确认 |

### 3. 朋友

**Malti:** Eżatt, niltaqgħu fit-tmienja u nofs u nidħlu ġewwa l-ħanut.

**整句：** 正是，我们八点半见，然后进店里。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Eżatt | 正是；准确 | 借词 exact |
| niltaqgħu | 我们见面 | 第一人称复数 |
| fit-tmienja u nofs | 在八点半 | 时间表达 |
| nidħlu | 我们进入 | 第一人称复数 |
| ġewwa | 里面 | 介词 |
| l-ħanut | 商店；店铺 | 阳性名词，带定冠词 |

### 4. 朋友

**Malti:** X'ser tilbes?

**整句：** 你要穿什么？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| X' | 什么 | `x'` 缩合形式 |
| ser | 将要 | 将来时标记 |
| tilbes | 你穿 | 第二人称单数 |

### 5. 朋友

**Malti:** Ħa tilbes ġakketta?

**整句：** 你会穿夹克吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Ħa | 将要 | 口语将来时标记 |
| tilbes | 你穿 | 第二人称单数 |
| ġakketta | 夹克 | 借词 jacket |

### 6. Claire

**Malti:** Qed ikun ftit bard u għalhekk naħseb nilbes ġakketta u flokk tas-suf.

**整句：** 天气有点冷，所以我想穿夹克和毛衣。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Qed | 正在 | 进行时标记 |
| ikun | 是 | `kun` 的现在时（天气） |
| ftit | 有点 | 程度副词 |
| bard | 冷 | 名词 |
| u | 并且 | 连词 |
| għalhekk | 因此 | `għal`+`hekk` |
| naħseb | 我想 | 第一人称单数 |
| nilbes | 我穿 | 第一人称单数 |
| flokk | 毛衣；针织衫 | 借词 |
| tas-suf | 羊毛的 | `ta'`+`is-suf` |

### 7. 朋友

**Malti:** Tajjeb, nilbes bħalek mela. It-tifel se iġġibuh magħkom?

**整句：** 好的，那我也穿一样的。孩子你们会带上吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tajjeb | 好的 | 形容词 |
| nilbes | 我穿 | 第一人称单数 |
| bħalek | 像你一样 | `bħal`+`-ek`（你的） |
| mela | 那么；那好吧 | 口语语气词 |
| It-tifel | 孩子；男孩 | 阳性名词，带定冠词 |
| se | 将要 | 将来时标记 |
| iġġibuh | 你们带他 | `iġġibu`+`-h`（他） |
| magħkom | 和你们 | `ma'`+`-kom`（你们） |

### 8. Claire

**Malti:** Jien u r-raġel, it-tifel ser inħalluh m'ommi.

**整句：** 我和我丈夫，孩子我们会留给我妈妈。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jien | 我 | 第一人称代词 |
| u | 和 | 连词 |
| r-raġel | 丈夫 | `raġel` 带定冠词 |
| it-tifel | 孩子 | 带定冠词 |
| ser | 将要 | 将来时标记 |
| inħalluh | 我们留下他 | `inħallu`+`-h` |
| m'ommi | 在我妈妈那里 | `ma'`+`ommi`（我妈妈） |

### 9. 朋友

**Malti:** Tajjeb, niltaqgħu mela. Saħħiet.

**整句：** 好的，那我们见面吧。再见。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tajjeb | 好的 | 形容词 |
| niltaqgħu | 我们见面 | 第一人称复数 |
| mela | 那么 | 语气词 |
| Saħħiet | 再见 | `saħħa` 的复数告别语 |

### 10. Claire

**Malti:** Iva, niltaqgħu. Saħħiet.

**整句：** 好的，我们见面。再见。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Iva | 是的；好的 | 肯定应答 |
| niltaqgħu | 我们见面 | 第一人称复数 |
| Saħħiet | 再见 | 告别语 |
