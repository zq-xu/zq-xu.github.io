# 租来的车

**场景：** Carmen Micallef 打电话给租车公司，要找 Martin Deguara 先生。对方不在，她向职员说明她十五天前租了车、现在周五要飞回自己的国家；双方商定她周五进机场前到位于机场停车场的办公室还车、检查车辆并退还 VISA 押金。

**来源：** 对话改编自 Charles Daniel Saliba 的《Speaking Maltese 2》（Djalogu addattat minn Speaking Maltese 2 ta' Charles Daniel Saliba）

## 完整对话

**Carmen（客户）：** Bonġu, jien Carmen Micallef. Nista' nkellem lis-Sur Martin Deguara, jekk jogħġbok?

**Tal-karozzi（租车公司职员）：** Skużani, illum Martin mhux hawn. Nista' naqdik jien?

**Carmen（客户）：** Ma jimpurtax, mela ħa nispjega kollox lilek. Ħmistax ilu kont krejt karozza mingħandkom u issa se nsiefer lura pajjiżi nhar il-Ġimgħa. Nixtieq inkun naf kif se ngħaddilkom il-karozza lura.

**Tal-karozzi（租车公司职员）：** Inti x'ħin se ssiefer il-Ġimgħa?

**Carmen（客户）：** It-titjira hija fid-disgħa ta' billejl.

**Tal-karozzi（租车公司职员）：** Tajjeb ħafna, mela l-Ġimgħa stess qabel tidħol l-ajruport ejja hawn l-uffiċċju tagħna li jinsab fil-parkeġġ tal-ajruport stess. Ikollna bżonn nispezzjonaw il-karozza u malli jkun kollox sew, nirrilaxxaw il-VISA tiegħek.

**Carmen（客户）：** Ok, naħseb ikunu xi s-sitta ta' flgħaxija kif nasal.

**Tal-karozzi（租车公司职员）：** Tajjeb, ikun hawn jien dak il-ħin.

**Carmen（客户）：** Sewwa wisq, mela narak il-Ġimgħa fis-sitta ta' flgħaxija. Grazzi!

**Tal-karozzi（租车公司职员）：** Grazzi lilek, saħħa!

## 逐句翻译与逐词拆解

### 1. Carmen（客户）

**Malti:** Bonġu, jien Carmen Micallef. Nista' nkellem lis-Sur Martin Deguara, jekk jogħġbok?

**整句：** 早上好，我是 Carmen Micallef。请问我能和 Martin Deguara 先生说话吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Bonġu | 早上好 | 正式问候语 |
| jien | 我 | 第一人称代词 |
| Carmen Micallef | 卡门·米卡莱夫 | 人名 |
| Nista' | 我能 | 第一人称单数 |
| nkellem | 我和……交谈 | kellem 的第一人称单数 |
| lis-Sur | 和先生 | `li`+`is-Sur` 缩合；Sur=先生 |
| Martin Deguara | 马丁·德瓜拉 | 人名 |
| jekk jogħġbok | 请 | 字面"如果你乐意" |

### 2. Tal-karozzi（租车公司职员）

**Malti:** Skużani, illum Martin mhux hawn. Nista' naqdik jien?

**整句：** 抱歉，今天 Martin 不在。我可以为您服务吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Skużani | 请原谅我；抱歉 | `skuża`+`-ni`（我） |
| illum | 今天 | 时间副词 |
| mhux | 不；没有 | 否定词 |
| hawn | 在这里 | 地点副词 |
| Nista' | 我能 | 第一人称单数 |
| naqdik | 我为您服务 | `naqdi`+`-k`（您） |
| jien | 我 | 强调"我来服务" |

### 3. Carmen（客户）

**Malti:** Ma jimpurtax, mela ħa nispjega kollox lilek. Ħmistax ilu kont krejt karozza mingħandkom u issa se nsiefer lura pajjiżi nhar il-Ġimgħa. Nixtieq inkun naf kif se ngħaddilkom il-karozza lura.

**整句：** 没关系，那我就跟您解释一切吧。十五天前我从你们那里租了一辆车，现在星期五我要飞回我的国家。我想知道该怎么把车还给你们。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Ma jimpurtax | 没关系 | `ma`+`jimpurta`+`x` 否定 |
| mela | 那么；那好吧 | 语气词 |
| ħa nispjega | 我来解释 | `ħa`（将要/让我）+nispjega（我解释） |
| kollox | 一切 | 不定代词 |
| lilek | 给你；向你说 | `li`+`-lek` |
| Ħmistax ilu | 十五天前 | ħmistax（十五）+ilu（……之前） |
| kont krejt | 我曾租了 | kont（过去助动词）+krejt（借词 hire/rent，第一人称过去时） |
| karozza | 汽车 | 阴性名词 |
| mingħandkom | 从你们那里 | `mingħand`+`-kom`（你们） |
| issa | 现在 | 副词 |
| se nsiefer | 我将飞往 | se（将来标记）+nsiefer（我旅行/飞行） |
| lura | 回去；返回 | 副词 |
| pajjiżi | 我的国家 | `pajjiż`+`-i`（我的） |
| nhar | 在……那天 | 字面"天" |
| il-Ġimgħa | 星期五 | 带定冠词 |
| Nixtieq | 我想要 | 第一人称单数 |
| inkun naf | 想知道 | inkun（我是）+naf（我知道） |
| kif | 怎样 | 疑问副词 |
| se ngħaddilkom | 我将交还给你们 | `ngħaddi`（我传递）+-lkom（给你们） |
| lura | 归还 | 此处作"还回去" |

### 4. Tal-karozzi（租车公司职员）

**Malti:** Inti x'ħin se ssiefer il-Ġimgħa?

**整句：** 您星期五几点出发？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Inti | 你；您 | 第二人称代词 |
| x'ħin | 什么时间 | `x'`（什么）+ħin（时间） |
| se ssiefer | 您将出发 | se+ssiefer（第二人称单数） |
| il-Ġimgħa | 星期五 | 带定冠词 |

### 5. Carmen（客户）

**Malti:** It-titjira hija fid-disgħa ta' billejl.

**整句：** 航班是晚上九点。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| It-titjira | 航班 | 阴性名词（借词） |
| hija | 是 | 第三人称阴性单数 |
| fid-disgħa | 在九点 | `f'`+`id-disgħa` |
| ta' billejl | 晚上的 | ta'（的）+billejl（夜晚；规范拼写 `bil-lejl`） |

### 6. Tal-karozzi（租车公司职员）

**Malti:** Tajjeb ħafna, mela l-Ġimgħa stess qabel tidħol l-ajruport ejja hawn l-uffiċċju tagħna li jinsab fil-parkeġġ tal-ajruport stess. Ikollna bżonn nispezzjonaw il-karozza u malli jkun kollox sew, nirrilaxxaw il-VISA tiegħek.

**整句：** 非常好。那就在星期五您进机场之前，来我们的办公室——它就在机场停车场里面。我们需要检查一下车，一旦一切都没问题，我们就退还您的 VISA 押金。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tajjeb ħafna | 非常好 | tajjeb（好）+ħafna（很） |
| l-Ġimgħa stess | 就在星期五当天 | stess（本身，加强语） |
| qabel | 在……之前 | 介词 |
| tidħol | 您进入 | 第二人称单数 |
| l-ajruport | 机场 | 借词 airport |
| ejja | 来吧 | 祈使语气 |
| hawn | 这里 | 地点副词 |
| l-uffiċċju | 办公室 | 借词 uffiċċju |
| tagħna | 我们的 | 所有格 |
| li jinsab | 它位于 | jinsab（位于，第三人称单数） |
| fil-parkeġġ | 在停车场 | `f'`+`il-parkeġġ` |
| tal-ajruport stess | 机场本身的 | ta'（的）+ajruport+stess |
| Ikollna bżonn | 我们将需要 | `ikollna`（我们有）+-bżonn（需要） |
| nispezzjonaw | 我们检查 | 借词 spezzjona |
| il-karozza | 车 | 带定冠词 |
| malli | 一旦 | 连词 |
| jkun kollox sew | 一切顺利 | jkun（是）+kollox（一切）+sew（好） |
| nirrilaxxaw | 我们退还；解除 | 借词 rilaxxa |
| il-VISA tiegħek | 您的 VISA 押金 | 租车场景中指退还 VISA 卡预授权/押金 |

### 7. Carmen（客户）

**Malti:** Ok, naħseb ikunu xi s-sitta ta' flgħaxija kif nasal.

**整句：** 好的，我想我到的时候大概是晚上六点。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Ok | 好的 | 借词 |
| naħseb | 我想 | 第一人称单数 |
| ikunu | 会是 | 复数将来（指时间点） |
| xi | 大约 | 副词 |
| s-sitta | 六点 | `is-sitta`（六） |
| ta' flgħaxija | 晚上的 | 原文 `flgħaxija`，规范拼写 `filgħaxija` |
| kif nasal | 当我到达 | kif（当）+nasal（我到达，第一人称单数） |

### 8. Tal-karozzi（租车公司职员）

**Malti:** Tajjeb, ikun hawn jien dak il-ħin.

**整句：** 好的，那个时间我会在这里。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tajjeb | 好的 | 形容词 |
| ikun hawn jien | 我会在这里 | ikun（是）+hawn（这里）+jien（我） |
| dak il-ħin | 那个时间 | dak（那个）+il-ħin（时间） |

### 9. Carmen（客户）

**Malti:** Sewwa wisq, mela narak il-Ġimgħa fis-sitta ta' flgħaxija. Grazzi!

**整句：** 太好了，那星期五晚上六点见。谢谢！

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Sewwa wisq | 太好了 | sewwa（正确）++wisq（非常） |
| mela | 那么 | 语气词 |
| narak | 我见到您 | `nara`+`-k` |
| il-Ġimgħa | 星期五 | 带定冠词 |
| fis-sitta | 在六点 | `f'`+`is-sitta` |
| ta' flgħaxija | 晚上的 | 同上（filgħaxija） |
| Grazzi | 谢谢 | 礼貌用语 |

### 10. Tal-karozzi（租车公司职员）

**Malti:** Grazzi lilek, saħħa!

**整句：** 谢谢您，再见！

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi lilek | 谢谢您 | grazzi（谢谢）+lilek（给您） |
| saħħa | 再见；保重 | 字面"健康"，常用告别语 |
