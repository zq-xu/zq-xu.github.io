# 情景对话目录

本分类包含 5 篇马耳他语双人情景对话。每篇先完整列出对话，再提供逐句中文翻译和逐词拆解；文件编号在本分类内从 01 开始。

1. [预约医院就诊时间](01-hospital-appointment.md)：电话预约医生，并确认日期、时间和需要携带的证件。
2. [失物招领与警局领取](02-lost-property.md)：报告找到的钱包，并约定到警局领取的时间。
3. [参加周末派对](03-weekend-party.md)：朋友邀请对方参加周末派对，讨论时间、地点和携带物品。
4. [询问当前时间](04-asking-the-time.md)：询问时间、确认约会时间并说明迟到情况。
5. [闲聊近期计划](05-weekend-plans.md)：讨论今天、明天、本周末、下周、下个月和明年的安排。
