# 生日派对邀请邮件

**场景：** Anna 邀请朋友 Mark 参加自己的生日派对。

## 邮件头部

**Lil（收件人 To）：** mark.b@gmail.com
**Mingħand（发件人 From）：** anna.c@gmail.com
**Data（日期）：** 10 ta' Ottubru 2026
**Suġġett（主题）：** Stedina għall-festa ta' għeluq snini

## 邮件全文

> **Lil:** mark.b@gmail.com
> **Mingħand:** anna.c@gmail.com
> **Data:** 10 ta' Ottubru 2026
> **Suġġett:** Stedina għall-festa ta' għeluq snini
>
> Għażiż Mark,
>
> Nispera li inti tajjeb.
>
> Nixtieq nistedinkom għall-festa ta' għeluq snini nhar is-Sibt.
>
> Il-festa se tibda fis-sebgħa ta' filgħaxija.
>
> Se niltaqgħu d-dar tiegħi f'Valletta.
>
> Ikun hemm ikel, mużika u kejk.
>
> Tista' ġġib lil xi ħadd miegħek jekk trid.
>
> Jekk jogħġbok, għidli jekk ġej.
>
> Nistenna bil-ħerqa li niċċelebraw flimkien.
>
> Tislijiet,
> Anna

## 逐句翻译与逐词拆解

**Malti:** Lil: mark.b@gmail.com

**整句：** 收件人（To）：mark.b@gmail.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Lil | 收件人；给…… | 邮件头部"To"的马耳他语标签 |
| mark.b@gmail.com | 邮箱地址 | 收件人（Mark）的邮箱 |

**Malti:** Mingħand: anna.c@gmail.com

**整句：** 发件人（From）：anna.c@gmail.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Mingħand | 发件人；来自…… | 邮件头部"From"的马耳他语标签，本义"从……那里" |
| anna.c@gmail.com | 邮箱地址 | 发件人（Anna）的邮箱 |

**Malti:** Data: 10 ta' Ottubru 2026

**整句：** 日期：2026 年 10 月 10 日

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Data | 日期 | 邮件头部"Date"；马耳他语日期格式为"日 ta' 月 年" |
| 10 | 十 | 日期中的日 |
| ta' | ……的 | 连接日和月份 |
| Ottubru | 十月 | 月份名 |

**Malti:** Suġġett: Stedina għall-festa ta' għeluq snini

**整句：** 主题：生日派对邀请

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Suġġett | 主题 | 邮件头部"Subject" |
| Stedina | 邀请 | 阴性名词 |
| għall-festa | 去派对；参加派对 | `għal` + `il-festa` 的缩合形式 |
| ta' | ……的 | 所属连接词 |
| għeluq | 庆祝；周年 | 与 `għeluq snini` 连用表示生日 |
| snini | 我的年岁 | `snin`“年” + `-i` 第一人称所有格 |

**Malti:** Għażiż Mark,

**整句：** 亲爱的马克：

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għażiż | 亲爱的 | 阳性单数形式，用于称呼男性 |
| Mark | 马克 | 人名 |

### 1.

**Malti:** Nispera li inti tajjeb.

**整句：** 希望你一切都好。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nispera | 我希望 | 第一人称单数形式 |
| li | ……这件事；引导从句 | 连词 |
| inti | 你 | 第二人称单数代词 |
| tajjeb | 好的 | 阳性形式；女性对象可用 `tajba` |

### 2.

**Malti:** Nixtieq nistedinkom għall-festa ta' għeluq snini nhar is-Sibt.

**整句：** 我想邀请你们星期六来参加我的生日派对。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nixtieq | 我想要；我希望 | 礼貌表达愿望 |
| nistedinkom | 我邀请你们 | `nistieden`“我邀请” + `-kom`“你们” |
| għall-festa | 去派对；参加派对 | `għal` + `il-festa` 的缩合形式 |
| ta' | ……的 | 所属/类别连接词 |
| għeluq | 庆祝；周年 | 与 `għeluq snini` 连用表示生日 |
| snini | 我的年岁；我的岁数 | `snin`“年” + `-i` 第一人称所有格 |
| nhar | 在……那天 | 引出星期或日期 |
| is-Sibt | 星期六 | 星期名称通常带定冠词 |

### 3.

**Malti:** Il-festa se tibda fis-sebgħa ta' filgħaxija.

**整句：** 派对将在晚上七点开始。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Il-festa | 派对 | 定冠词 + `festa` |
| se | 将；会 | 将来标记 |
| tibda | 开始 | 第三人称阴性单数，与 `festa` 呼应 |
| fis-sebgħa | 在七点 | `f'` + 定冠词钟点形式缩合 |
| ta' | ……的；在……时段 | 连接钟点和时段 |
| filgħaxija | 在晚上 | 时间表达 |

### 4.

**Malti:** Se niltaqgħu d-dar tiegħi f'Valletta.

**整句：** 我们将在我瓦莱塔的家里见面。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Se | 将；会 | 将来标记 |
| niltaqgħu | 我们见面 | 第一人称复数形式 |
| d-dar | 在家；家里 | `id-dar` 的常见缩合形式 |
| tiegħi | 我的 | 所有格代词 |
| f'Valletta | 在瓦莱塔 | `f'` + 地名；通常不加冠词 |

### 5.

**Malti:** Ikun hemm ikel, mużika u kejk.

**整句：** 会有食物、音乐和蛋糕。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Ikun | 会有；会是 | 第三人称形式，常用于表示将来存在 |
| hemm | 有；那里 | 与 `ikun` 连用表示“会有” |
| ikel | 食物 | 阳性集合名词 |
| mużika | 音乐 | 阴性名词 |
| u | 和 | 连词 |
| kejk | 蛋糕 | 阳性名词，借词 |

### 6.

**Malti:** Tista' ġġib lil xi ħadd miegħek jekk trid.

**整句：** 如果你愿意，可以带一个人一起来。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tista' | 你可以 | 第二人称单数形式 |
| ġġib | 带来 | `ġib`“带来”的变位形式 |
| lil | 对；给；引出人的宾语 | 人称宾语标记/介词 |
| xi | 某个；一些 | 不定限定词 |
| ħadd | 人 | 与 `xi` 连用表示“某个人” |
| miegħek | 和你一起 | `miegħ`“和” + `-ek`“你” |
| jekk | 如果 | 连词 |
| trid | 你想；你愿意 | 第二人称单数形式 |

### 7.

**Malti:** Jekk jogħġbok, għidli jekk ġej.

**整句：** 麻烦告诉我你是否会来。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jekk jogħġbok | 请；麻烦你 | 固定礼貌表达 |
| għidli | 告诉我 | `għid`“说/告诉” + `-li`“我” |
| jekk | 是否；如果 | 此处引出间接疑问 |
| ġej | 来；将来 | 阳性形式；女性对象可用 `ġejja` |

### 8.

**Malti:** Nistenna bil-ħerqa li niċċelebraw flimkien.

**整句：** 我期待和你们一起庆祝。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nistenna | 我等待；我期待 | 第一人称单数形式 |
| bil-ħerqa | 期待地；热切地 | 固定副词短语 |
| li | ……；引出从句 | 连词 |
| niċċelebraw | 我们庆祝 | 第一人称复数形式 |
| flimkien | 一起 | 副词 |

**Malti:** Tislijiet, Anna

**整句：** 此致敬意，安娜（邮件落款）。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tislijiet | 此致敬意；致以问候 | 正式邮件/信件落款用语，本义"问候/致意" |
| Anna | 安娜 | 人名 |
