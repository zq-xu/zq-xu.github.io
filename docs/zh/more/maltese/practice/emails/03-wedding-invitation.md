# 婚礼邀请邮件

**场景：** 一对新人邀请亲友参加婚礼仪式和宴会。

## 邮件全文

> Għeżież ħbieb,
>
> Għandna pjaċir nistednukom għat-tieġ tagħna.
>
> Iċ-ċerimonja se ssir nhar is-Sibt, 18 ta' Lulju.
>
> Tibda fil-ħamsa ta' wara nofsinhar fil-knisja ta' San Pawl.
>
> Wara ċ-ċerimonja, se jkun hemm riċeviment fil-lukanda Marina.
>
> Jekk jogħġobkom, ikkonfermaw jekk tistgħux tattendu sal-1 ta' Lulju.
>
> Nistennew bil-ħerqa li niċċelebraw dan il-jum speċjali magħkom.
>
> Dejjem tagħkom, Anna u Mark

## 逐句翻译与逐词拆解

**Malti:** Għeżież ħbieb,

**整句：** 亲爱的朋友们：

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għeżież | 亲爱的 | 阳性复数形式，用于称呼一群人 |
| ħbieb | 朋友们 | `ħabib` 的复数 |

### 1.

**Malti:** Għandna pjaċir nistednukom għat-tieġ tagħna.

**整句：** 我们很高兴邀请你们参加我们的婚礼。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandna | 我们有 | `għand` 的第一人称复数形式 |
| pjaċir | 愉快；荣幸 | `għandna pjaċir` 整体表示“我们很高兴/荣幸” |
| nistednukom | 我们邀请你们 | `nistiednu`“我们邀请” + `-kom`“你们” |
| għat-tieġ | 去婚礼；参加婚礼 | `għal` + `it-tieġ` 的缩合形式 |
| tagħna | 我们的 | 第一人称复数所有格 |

### 2.

**Malti:** Iċ-ċerimonja se ssir nhar is-Sibt, 18 ta' Lulju.

**整句：** 婚礼仪式将于 7 月 18 日星期六举行。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Iċ-ċerimonja | 仪式 | 阴性名词，带定冠词 |
| se | 将；会 | 将来标记 |
| ssir | 举行；发生 | `isir` 的阴性形式，与 `ċerimonja` 一致 |
| nhar | 在……那天 | 引出星期或日期 |
| is-Sibt | 星期六 | 星期名称带定冠词 |
| 18 | 十八 | 日期中的日 |
| ta' | ……的 | 日期结构中连接日和月份 |
| Lulju | 七月 | 月份名 |

### 3.

**Malti:** Tibda fil-ħamsa ta' wara nofsinhar fil-knisja ta' San Pawl.

**整句：** 仪式下午五点在圣保罗教堂开始。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tibda | 它开始 | 第三人称阴性单数，指仪式 |
| fil-ħamsa | 在五点 | `f'`“在” + 钟点形式缩合 |
| ta' | ……的；在……时段 | 连接时间和时段 |
| wara | 之后 | 与 `nofsinhar` 合成“下午” |
| nofsinhar | 中午 | `wara nofsinhar` 表示下午 |
| fil-knisja | 在教堂 | `f'` + `il-knisja` 的缩合形式 |
| ta' | ……的 | 连接地点名称 |
| San | 圣 | 人名前的称谓 |
| Pawl | 保罗 | 人名 |

### 4.

**Malti:** Wara ċ-ċerimonja, se jkun hemm riċeviment fil-lukanda Marina.

**整句：** 仪式之后，我们将在 Marina 酒店举行宴会。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Wara | 在……之后 | 时间介词 |
| ċ-ċerimonja | 仪式 | `iċ-ċerimonja` 在此处省去句首元音写法，指婚礼仪式 |
| se | 将；会 | 将来标记 |
| jkun | 会是；会有 | `ikun` 的形式 |
| hemm | 有；那里 | `se jkun hemm` 表示“将会有” |
| riċeviment | 招待会；宴会 | 阳性名词，借词 |
| fil-lukanda | 在酒店 | `f'` + `il-lukanda` 的缩合形式 |
| Marina | Marina | 酒店名称 |

### 5.

**Malti:** Jekk jogħġobkom, ikkonfermaw jekk tistgħux tattendu sal-1 ta' Lulju.

**整句：** 麻烦你们在 7 月 1 日前确认是否能够出席。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jekk jogħġobkom | 请；麻烦你们 | 对多人使用的礼貌表达 |
| ikkonfermaw | 请确认 | 对多人的命令式 |
| jekk | 是否；如果 | 此处引出间接疑问 |
| tistgħux | 你们能否 | `tistgħu`“你们能够” + 否定/疑问标记 `-x` |
| tattendu | 你们出席 | 第二人称复数形式 |
| sal-1 | 到……为止；截至 1 日 | `sa` + `l-` 的缩合形式 |
| ta' | ……的 | 日期结构连接词 |
| Lulju | 七月 | 月份名 |

### 6.

**Malti:** Nistennew bil-ħerqa li niċċelebraw dan il-jum speċjali magħkom.

**整句：** 我们期待和你们一起庆祝这个特别的日子。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nistennew | 我们等待；我们期待 | 第一人称复数形式 |
| bil-ħerqa | 热切地；期待地 | 固定副词短语 |
| li | ……；引出从句 | 连词 |
| niċċelebraw | 我们庆祝 | 第一人称复数形式 |
| dan | 这个 | 阳性单数指示词，与 `jum` 一致 |
| il-jum | 日子 | 阳性名词，带定冠词 |
| speċjali | 特别的 | 形容词 |
| magħkom | 和你们一起 | `ma'`“和” + `-kom`“你们” |

**Malti:** Dejjem tagħkom, Anna u Mark

**整句：** 永远属于你们的，安娜和马克（邮件落款）。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Dejjem | 永远 | 副词 |
| tagħkom | 你们的 | 第二人称复数所有格形式，落款用语 |
| Anna | 安娜 | 人名 |
| u | 和 | 连词 |
| Mark | 马克 | 人名 |
