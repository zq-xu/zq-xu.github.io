# 回复婚礼邀请邮件

**场景：** 一位受邀者回复新人，确认自己和配偶会出席婚礼。

## 邮件全文

> Għeżież Anna u Mark,
>
> Grazzi tal-istedina għat-tieġ tagħkom.
>
> Ninsabu kuntenti li nikkonfermaw li se nattendu.
>
> Jien u marti se niġu għaċ-ċerimonja u għar-riċeviment.
>
> Naslu fil-ħin.
>
> Għandna nġibu xi ħaġa għalikom?
>
> Nawguralkom ħafna hena u mħabba fil-ħajja miżżewġa tagħkom.
>
> Nistennew bil-ħerqa li niċċelebraw magħkom.
>
> Grazzi mill-ġdid. Dejjem tagħkom, David

## 逐句翻译与逐词拆解

**Malti:** Għeżież Anna u Mark,

**整句：** 亲爱的安娜和马克：

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għeżież | 亲爱的 | 阳性复数称呼形式 |
| Anna | 安娜 | 人名 |
| u | 和 | 连词 |
| Mark | 马克 | 人名 |

### 1.

**Malti:** Grazzi tal-istedina għat-tieġ tagħkom.

**整句：** 感谢你们邀请我们参加婚礼。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi | 谢谢 | 礼貌用语 |
| tal-istedina | 因为邀请；邀请的 | `ta' + l-istedina` 的缩合形式 |
| għat-tieġ | 去婚礼；参加婚礼 | `għal` + `it-tieġ` 的缩合形式 |
| tagħkom | 你们的 | 第二人称复数所有格 |

### 2.

**Malti:** Ninsabu kuntenti li nikkonfermaw li se nattendu.

**整句：** 我们很高兴确认会出席。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Ninsabu | 我们处于；我们感到 | 第一人称复数形式 |
| kuntenti | 高兴的 | 复数形式 |
| li | ……；引出从句 | 连词 |
| nikkonfermaw | 我们确认 | 第一人称复数形式 |
| li | ……；引出从句 | 连词 |
| se | 将；会 | 将来标记 |
| nattendu | 我们出席 | 第一人称复数形式 |

### 3.

**Malti:** Jien u marti se niġu għaċ-ċerimonja u għar-riċeviment.

**整句：** 我和我妻子会参加仪式和宴会。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jien | 我 | 强调代词 |
| u | 和 | 连词 |
| marti | 我的妻子 | `mara`“妻子/女人” + 第一人称所有格形式 |
| se | 将；会 | 将来标记 |
| niġu | 我们来 | 第一人称复数形式 |
| għaċ-ċerimonja | 去仪式；参加仪式 | `għal` + `iċ-ċerimonja` 的缩合形式 |
| u | 和 | 连词 |
| għar-riċeviment | 去宴会；参加宴会 | `għal` + `ir-riċeviment` 的缩合形式 |

### 4.

**Malti:** Naslu fil-ħin.

**整句：** 我们会准时到。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Naslu | 我们到达 | 第一人称复数形式；此处表达将来安排 |
| fil-ħin | 准时；在时间内 | `f'` + `il-ħin` 的缩合形式 |

### 5.

**Malti:** Għandna nġibu xi ħaġa għalikom?

**整句：** 我们需要给你们带些什么吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandna | 我们有；我们需要 | 第一人称复数形式；与后续动词连用可表达需要/应该 |
| nġibu | 我们带来 | 第一人称复数形式 |
| xi | 一些；什么 | 疑问句中表示“什么” |
| ħaġa | 东西 | 阴性名词 |
| għalikom | 给你们；为了你们 | `għal`“给” + `-kom`“你们” |

### 6.

**Malti:** Nawguralkom ħafna hena u mħabba fil-ħajja miżżewġa tagħkom.

**整句：** 祝你们婚后生活幸福美满、充满爱意。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nawguralkom | 我祝愿你们 | `nawgura`“我祝愿” + `-lkom`“你们” |
| ħafna | 很多；非常 | 程度/数量词 |
| hena | 幸福；快乐 | 阳性名词 |
| u | 和 | 连词 |
| mħabba | 爱 | 阴性名词 |
| fil-ħajja | 在生活中 | `f'` + `il-ħajja` 的缩合形式 |
| miżżewġa | 已婚的 | 阴性形式，与 `ħajja` 一致 |
| tagħkom | 你们的 | 第二人称复数所有格 |

### 7.

**Malti:** Nistennew bil-ħerqa li niċċelebraw magħkom.

**整句：** 我们期待和你们一起庆祝。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nistennew | 我们等待；我们期待 | 第一人称复数形式 |
| bil-ħerqa | 热切地；期待地 | 固定副词短语 |
| li | ……；引出从句 | 连词 |
| niċċelebraw | 我们庆祝 | 第一人称复数形式 |
| magħkom | 和你们一起 | `ma'`“和” + `-kom`“你们” |

**Malti:** Grazzi mill-ġdid. Dejjem tagħkom, David

**整句：** 再次感谢。永远属于你们的，大卫。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi | 谢谢 | 礼貌用语 |
| mill-ġdid | 再一次 | `minn` + `il-ġdid` 的固定缩合表达 |
| Dejjem | 永远 | 副词 |
| tagħkom | 你们的 | 邮件落款用语 |
| David | 大卫 | 人名 |
