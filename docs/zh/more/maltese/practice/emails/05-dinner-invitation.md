# 晚餐邀请邮件

**场景：** Anna 邀请朋友 Mark 到家里吃晚餐。

## 邮件头部

**Lil（收件人 To）：** mark.b@gmail.com
**Mingħand（发件人 From）：** anna.c@gmail.com
**Data（日期）：** 12 ta' Ottubru 2026
**Suġġett（主题）：** Stedina għall-ikla ta' filgħaxija

## 邮件全文

> **Lil:** mark.b@gmail.com
> **Mingħand:** anna.c@gmail.com
> **Data:** 12 ta' Ottubru 2026
> **Suġġett:** Stedina għall-ikla ta' filgħaxija
>
> Għażiż Mark,
>
> Nispera li inti tajjeb.
>
> Nixtieq nistednek għall-ikla ta' filgħaxija d-dar tiegħi nhar il-Ġimgħa.
>
> Se nibdew fis-sebgħa ta' filgħaxija.
>
> Se nkunu ftit ħbieb u nieklu flimkien.
>
> Se nipprepara platt Malti u deżerta.
>
> Jekk jogħġbok, għidli jekk għandek xi preferenzi għall-ikel.
>
> Nispera li tkun tista' tiġi.
>
> Tislijiet,
> Anna

## 逐句翻译与逐词拆解

**Malti:** Lil: mark.b@gmail.com

**整句：** 收件人（To）：mark.b@gmail.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Lil | 收件人；给…… | 邮件头部"To"的马耳他语标签 |
| mark.b@gmail.com | 邮箱地址 | 收件人（Mark）的邮箱 |

**Malti:** Mingħand: anna.c@gmail.com

**整句：** 发件人（From）：anna.c@gmail.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Mingħand | 发件人；来自…… | 邮件头部"From"的马耳他语标签，本义"从……那里" |
| anna.c@gmail.com | 邮箱地址 | 发件人（Anna）的邮箱 |

**Malti:** Data: 12 ta' Ottubru 2026

**整句：** 日期：2026 年 10 月 12 日

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Data | 日期 | 邮件头部"Date"；马耳他语日期格式为"日 ta' 月 年" |
| 12 | 十二 | 日期中的日 |
| ta' | ……的 | 连接日和月份 |
| Ottubru | 十月 | 月份名 |

**Malti:** Suġġett: Stedina għall-ikla ta' filgħaxija

**整句：** 主题：晚餐邀请

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Suġġett | 主题 | 邮件头部"Subject" |
| Stedina | 邀请 | 阴性名词 |
| għall-ikla | 参加晚餐 | `għal` + `l-ikla` 的缩合形式 |
| ta' | ……的；在……时段 | 连接名词和时间表达 |
| filgħaxija | 在晚上 | 时间表达 |

**Malti:** Għażiż Mark,

**整句：** 亲爱的马克：

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għażiż | 亲爱的 | 阳性单数称呼形式 |
| Mark | 马克 | 人名 |

### 1.

**Malti:** Nispera li inti tajjeb.

**整句：** 希望你一切都好。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nispera | 我希望 | 第一人称单数形式 |
| li | ……；引导从句 | 连词 |
| inti | 你 | 第二人称单数代词 |
| tajjeb | 好的 | 阳性形式；女性形式为 `tajba` |

### 2.

**Malti:** Nixtieq nistednek għall-ikla ta' filgħaxija d-dar tiegħi nhar il-Ġimgħa.

**整句：** 我想邀请你星期五晚上到我家吃晚餐。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nixtieq | 我想；我希望 | 礼貌表达愿望 |
| nistednek | 我邀请你 | 邀请动词的第一人称形式，含第二人称单数宾语后缀 |
| għall-ikla | 去吃饭；参加晚餐 | `għal` + 定冠词 `l-` 与 `ikla` 缩合 |
| ta' | ……的；在……时段 | 连接名词和时间表达 |
| filgħaxija | 在晚上 | 时间表达 |
| d-dar | 在家；家里 | `id-dar` 的常见缩合写法 |
| tiegħi | 我的 | 第一人称单数所有格 |
| nhar | 在……那天 | 引出星期或日期 |
| il-Ġimgħa | 星期五 | 星期名称通常带定冠词 |

### 3.

**Malti:** Se nibdew fis-sebgħa ta' filgħaxija.

**整句：** 我们将在晚上七点开始。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Se | 将；会 | 将来标记 |
| nibdew | 我们开始 | 第一人称复数形式 |
| fis-sebgħa | 在七点 | `f'` 与钟点定冠词形式缩合 |
| ta' | ……的；在……时段 | 连接钟点与时段 |
| filgħaxija | 在晚上 | 时间表达 |

### 4.

**Malti:** Se nkunu ftit ħbieb u nieklu flimkien.

**整句：** 会有几个朋友，我们一起吃饭。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Se | 将；会 | 将来标记 |
| nkunu | 我们将会是；我们会在 | `ikun` 的第一人称复数形式 |
| ftit | 几个；少量 | 数量词 |
| ħbieb | 朋友们 | `ħabib` 的复数 |
| u | 和；并且 | 连词 |
| nieklu | 我们吃 | 第一人称复数形式 |
| flimkien | 一起 | 副词 |

### 5.

**Malti:** Se nipprepara platt Malti u deżerta.

**整句：** 我会准备一道马耳他菜和甜点。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Se | 将；会 | 将来标记 |
| nipprepara | 我准备 | 第一人称单数形式 |
| platt | 一道菜；盘子 | 阳性名词；此处指一道菜 |
| Malti | 马耳他式的 | 阳性单数形式，与 `platt` 一致 |
| u | 和 | 连词 |
| deżerta | 甜点 | 阴性名词 |

### 6.

**Malti:** Jekk jogħġbok, għidli jekk għandek xi preferenzi għall-ikel.

**整句：** 麻烦告诉我，你对食物有什么偏好吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jekk jogħġbok | 请；麻烦你 | 固定礼貌表达 |
| għidli | 告诉我 | `għid`“告诉” + `-li`“我” |
| jekk | 是否；如果 | 此处引出间接疑问 |
| għandek | 你有 | `għand` 的第二人称单数形式 |
| xi | 一些；任何 | 不定限定词 |
| preferenzi | 偏好 | `preferenza` 的复数 |
| għall-ikel | 对食物；关于吃的 | `għal` + 定冠词 `l-` 与 `ikel` 缩合 |

### 7.

**Malti:** Nispera li tkun tista' tiġi.

**整句：** 希望你能来。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nispera | 我希望 | 第一人称单数形式 |
| li | ……；引导从句 | 连词 |
| tkun | 你会是；你能够 | `ikun` 的第二人称/从属形式 |
| tista' | 你可以 | 第二人称单数形式 |
| tiġi | 你来 | 第二人称单数形式 |

**Malti:** Tislijiet, Anna

**整句：** 此致敬意，安娜（邮件落款）。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tislijiet | 此致敬意；致以问候 | 正式邮件/信件落款用语，本义"问候/致意" |
| Anna | 安娜 | 人名 |
