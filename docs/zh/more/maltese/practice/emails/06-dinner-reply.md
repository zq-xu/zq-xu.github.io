**Suġġett（主题）：** Risposta għall-ikla ta' filgħaxija

## 逐句翻译与逐词拆解

**Malti:** Lil: anna.c@gmail.com

**整句：** 收件人（To）：anna.c@gmail.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Lil | 收件人；给…… | 邮件头部"To"的马耳他语标签 |
| anna.c@gmail.com | 邮箱地址 | 收件人（Anna）的邮箱 |

**Malti:** Mingħand: mark.b@gmail.com

**整句：** 发件人（From）：mark.b@gmail.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Mingħand | 发件人；来自…… | 邮件头部"From"的马耳他语标签，本义"从……那里" |
| mark.b@gmail.com | 邮箱地址 | 发件人（Mark）的邮箱 |

**Malti:** Data: 14 ta' Ottubru 2026

**整句：** 日期：2026 年 10 月 14 日

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Data | 日期 | 邮件头部"Date"；马耳他语日期格式为"日 ta' 月 年" |
| 14 | 十四 | 日期中的日 |
| ta' | ……的 | 连接日和月份 |
| Ottubru | 十月 | 月份名 |

**Malti:** Suġġett: Risposta għall-ikla ta' filgħaxija

**整句：** 主题：回复晚餐邀请

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Suġġett | 主题 | 邮件头部"Subject" |
| Risposta | 回复；答复 | 阴性名词 |
| għall-ikla | 针对晚餐；回应晚餐邀请 | `għal` + `l-ikla` 的缩合形式 |
| ta' | ……的；在……时段 | 连接名词和时间表达 |
| filgħaxija | 在晚上 | 时间表达 |

**Malti:** Għażiża Anna,

**整句：** 亲爱的安娜：

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għażiża | 亲爱的 | 阴性单数称呼形式 |
| Anna | 安娜 | 人名 |

### 1.

**Malti:** Grazzi tal-istedina għall-ikla ta' filgħaxija.

**整句：** 感谢你邀请我参加晚餐。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi | 谢谢 | 礼貌用语 |
| tal-istedina | 因为邀请；邀请的 | `ta'` 与定冠词缩合 |
| għall-ikla | 去吃饭；参加晚餐 | `għal` 与定冠词缩合 |
| ta' | ……的；在……时段 | 连接名词和时间表达 |
| filgħaxija | 在晚上 | 时间表达 |

### 2.

**Malti:** Iva, se niġi nhar il-Ġimgħa.

**整句：** 好的，我星期五会来。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Iva | 是；好的 | 肯定回答 |
| se | 将；会 | 将来标记 |
| niġi | 我来 | 第一人称单数形式 |
| nhar | 在……那天 | 引出星期或日期 |
| il-Ġimgħa | 星期五 | 星期名称通常带定冠词 |

### 3.

**Malti:** Se nasal fis-sebgħa.

**整句：** 我会七点到。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Se | 将；会 | 将来标记 |
| nasal | 我到达 | 第一人称单数形式 |
| fis-sebgħa | 在七点 | `f'` 与钟点定冠词形式缩合 |

### 4.

**Malti:** M'għandi l-ebda preferenza għall-ikel.

**整句：** 我对食物没有特别偏好。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| M'għandi | 我没有 | `ma għandix` 的缩合/否定形式之一 |
| l-ebda | 没有任何；不…… | 否定限定表达 |
| preferenza | 偏好 | 阴性名词 |
| għall-ikel | 对食物；关于吃的 | `għal` 与定冠词缩合 |

### 5.

**Malti:** Nista' nġib xi ħaġa għad-deżerta?

**整句：** 我可以带点甜点来吗？

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nista' | 我可以吗 | 第一人称单数形式 |
| nġib | 我带来 | 第一人称单数形式 |
| xi | 一些；某个 | 不定限定词 |
| ħaġa | 东西 | 阴性名词 |
| għad-deżerta | 用作甜点；作为甜点 | `għal` 与定冠词缩合 |

### 6.

**Malti:** Se nġib kejk żgħir.

**整句：** 我会带一个小蛋糕。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Se | 将；会 | 将来标记 |
| nġib | 我带来 | 第一人称单数形式 |
| kejk | 蛋糕 | 阳性名词 |
| żgħir | 小的 | 阳性单数形式，与 `kejk` 一致 |

### 7.

**Malti:** Nistenna bil-ħerqa li niltaqa' mal-ħbieb tiegħek.

**整句：** 我期待见到你的朋友们。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nistenna | 我等待；我期待 | 第一人称单数形式 |
| bil-ħerqa | 热切地；期待地 | 固定副词短语 |
| li | ……；引出从句 | 连词 |
| niltaqa' | 我见面 | 第一人称单数形式 |
| mal-ħbieb | 和朋友们 | `ma'` 与定冠词缩合 |
| tiegħek | 你的 | 第二人称单数所有格 |

**Malti:** Tislijiet, Mark

|---|---|---|
| Tislijiet | 此致敬意；致以问候 | 正式邮件/信件落款用语，本义"问候/致意" |
