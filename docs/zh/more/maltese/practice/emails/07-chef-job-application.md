# 餐厅厨师求职邮件

**场景：** 申请人写信给餐厅经理，申请餐厅的厨师职位。

## 邮件头部

**Lil（收件人 To）：** info@restorant.com
**Mingħand（发件人 From）：** [isem]@email.com
**Data（日期）：** 15 ta' Ottubru 2026
**Suġġett（主题）：** Applikazzjoni ta' xogħol ta' kok

> **Lil:** info@restorant.com
> **Mingħand:** [isem]@email.com
> **Data:** 15 ta' Ottubru 2026
> **Suġġett:** Applikazzjoni ta' xogħol ta' kok
>
> Għażiż Sinjur / Sinjura,
>

## 逐句翻译与逐词拆解

**Malti:** Lil: info@restorant.com

**整句：** 收件人（To）：info@restorant.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Lil | 收件人；给…… | 邮件头部"To"的马耳他语标签 |
| info@restorant.com | 邮箱地址 | 餐厅的招聘邮箱（示例） |

**Malti:** Mingħand: [isem]@email.com

**整句：** 发件人（From）：[你的名字]@email.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Mingħand | 发件人；来自…… | 邮件头部"From"的马耳他语标签，本义"从……那里" |
| [isem]@email.com | 邮箱地址 | 你的邮箱占位，请替换为真实邮箱 |

**Malti:** Data: 15 ta' Ottubru 2026

**整句：** 日期：2026 年 10 月 15 日

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Data | 日期 | 邮件头部"Date"；马耳他语日期格式为"日 ta' 月 年" |
| 15 | 十五 | 日期中的日 |
| ta' | ……的 | 连接日和月份 |
| Ottubru | 十月 | 月份名 |

**Malti:** Suġġett: Applikazzjoni ta' xogħol ta' kok

**整句：** 主题：厨师职位申请

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Suġġett | 主题 | 邮件头部"Subject" |
| Applikazzjoni | 申请 | 阴性名词，借词 application |
| ta' | ……的 | 所属连接词 |
| xogħol | 工作；职位 | 阳性名词 |
| ta' | ……的 | 所属连接词 |
| kok | 厨师 | 阳性名词，借词 cook |

**Malti:** Għażiż Sinjur / Sinjura,

**整句：** 亲爱的先生 / 女士：

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għażiż | 亲爱的 | 阳性单数形式 |
| Sinjur | 先生 | 阳性名词 |
| / | 或 | 表示二选一 |
| Sinjura | 女士 | 阴性名词 |

### 1.

**Malti:** Qed nikteb biex napplika għall-impjieg ta' kok fir-ristorant tagħkom.

**整句：** 我写信是为了申请你们餐厅的厨师职位。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Qed | 正在（进行时标记） | 与动词连用表示正在做某事 |
| nikteb | 我写 | 第一人称单数现在时 |
| biex | 为了 | 引出目的状语 |
| napplika | 我申请 | 第一人称单数形式，借词 apply |
| għall-impjieg | 申请职位 | `għal`“为了” + `l-impjieg`“职位”缩合 |
| ta' | ……的 | 所属/类别连接词 |
| kok | 厨师 | 阳性名词，借词 cook |
| fir-ristorant | 在餐厅 | `f'`“在” + `ir-ristorant` 缩合 |
| tagħkom | 你们的 | 复数所有格代词 |

### 2.

**Malti:** Għandi ħames snin esperjenza fil-kċina.

**整句：** 我有五年的厨房经验。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandi | 我有 | `għand`“有”的第一人称单数形式 |
| ħames | 五 | 数词，后接复数名词 |
| snin | 年 | `sena`“年”的复数形式 |
| esperjenza | 经验 | 阴性名词 |
| fil-kċina | 在厨房 | `f'` + `il-kċina` 缩合 |

### 3.

**Malti:** Naf insajjar platti tradizzjonali Maltin u Mediterranji.

**整句：** 我会做传统的马耳他和地中海菜肴。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Naf | 我知道；我会 | 第一人称单数形式 |
| insajjar | 我烹饪 | 第一人称单数现在时 |
| platti | 菜肴 | `platt`“盘子/菜”的复数 |
| tradizzjonali | 传统的 | 形容词 |
| Maltin | 马耳他的 | `Malti` 的复数形式 |
| u | 和 | 连词 |
| Mediterranji | 地中海的 | 形容词复数形式 |

### 4.

**Malti:** Jien bniedem li jaħdem iebes u jimpurtani mill-kwalità tal-ikel.

**整句：** 我是一个努力工作并且在意食物质量的人。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jien | 我 | 第一人称单数代词 |
| bniedem | 人 | 阳性名词 |
| li | ……的；引出关系从句 | 关系代词 |
| jaħdem | 他工作 | 第三人称阳性单数 |
| iebes | 努力地；刻苦的 | 此处作副词“努力地” |
| u | 和 | 连词 |
| jimpurtani | 我在意 | `jimpurta` + `-ni`“我”，惯用表达 |
| mill-kwalità | 关于质量 | `minn`“从/关于” + `il-kwalità` 缩合 |
| tal-ikel | 食物的 | `ta'` + `l-ikel` 缩合 |

### 5.

**Malti:** Naħdem ukoll tajjeb ma' tim.

**整句：** 我也能和团队很好地合作。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Naħdem | 我工作 | 第一人称单数现在时 |
| ukoll | 也；同样 | 副词 |
| tajjeb | 好；很好 | 此处作副词 |
| ma' | 和；与 | 介词 |
| tim | 团队 | 阳性名词，借词 team |

### 6.

**Malti:** Nixtieq niltaqgħa miegħkom għal intervista meta jkun konvenjenti.

**整句：** 我希望在你们方便的时候进行面试。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nixtieq | 我想要；我希望 | 礼貌表达愿望 |
| niltaqgħa | 我见面 | 第一人称单数形式 |
| miegħkom | 和你们 | `miegħ`“和” + `-kom`“你们” |
| għal | 为了 | 介词 |
| intervista | 面试 | 阴性名词，借词 interview |
| meta | 当……时候 | 连词 |
| jkun | 会是 | 第三人称单数，与 `konvenjenti` 连用 |
| konvenjenti | 方便的 | 形容词 |

### 7.

**Malti:** Grazzi ħafna talli qiesu l-applikazzjoni tiegħi.

**整句：** 非常感谢你们考虑我的申请。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi | 谢谢 | 礼貌用语 |
| ħafna | 很；非常 | 程度副词 |
| talli | 因为（你们）…… | 引出原因的书面表达 |
| qiesu | 他们考虑了 | `qies`“考虑/看”的第三人称复数过去时 |
| l-applikazzjoni | 申请 | 阴性名词，带定冠词 |
| tiegħi | 我的 | 所有格代词 |

### 8.

**Malti:** Nispera li nisma' mingħandkom dalwaqt.

**整句：** 我希望很快收到你们的回复。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nispera | 我希望 | 第一人称单数形式 |
| li | ……；引出从句 | 连词 |
| nisma' | 我听到；我收到消息 | 第一人称单数形式 |
| mingħandkom | 从你们那里 | `mingħand`“从……那里” + `-kom`“你们” |
| dalwaqt | 很快 | 副词，`dal-`“这个” + `waqt`“时刻” |
