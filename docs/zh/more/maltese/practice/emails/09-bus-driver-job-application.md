# 公交车司机求职邮件

**场景：** 申请人写信给公交公司，申请公交车司机职位。

## 邮件头部

**Lil（收件人 To）：** info@transport.com
**Mingħand（发件人 From）：** [isem]@email.com
**Data（日期）：** 15 ta' Ottubru 2026
**Suġġett（主题）：** Applikazzjoni ta' xogħol ta' sewwieq tal-karozza tal-linja

## 逐句翻译与逐词拆解

**Malti:** Lil: info@transport.com

**整句：** 收件人（To）：info@transport.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Lil | 收件人；给…… | 邮件头部"To"的马耳他语标签 |
| info@transport.com | 邮箱地址 | 公交公司的招聘邮箱（示例） |

**Malti:** Mingħand: [isem]@email.com

**整句：** 发件人（From）：[你的名字]@email.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Mingħand | 发件人；来自…… | 邮件头部"From"的马耳他语标签，本义"从……那里" |
| [isem]@email.com | 邮箱地址 | 你的邮箱占位，请替换为真实邮箱 |

**Malti:** Data: 15 ta' Ottubru 2026

**整句：** 日期：2026 年 10 月 15 日

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Data | 日期 | 邮件头部"Date"；马耳他语日期格式为"日 ta' 月 年" |
| 15 | 十五 | 日期中的日 |
| ta' | ……的 | 连接日和月份 |
| Ottubru | 十月 | 月份名 |

**Malti:** Suġġett: Applikazzjoni ta' xogħol ta' sewwieq tal-karozza tal-linja

**整句：** 主题：公交车司机职位申请

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Suġġett | 主题 | 邮件头部"Subject" |
| Applikazzjoni | 申请 | 阴性名词，借词 application |
| ta' | ……的 | 所属连接词 |
| xogħol | 工作；职位 | 阳性名词 |
| ta' | ……的 | 所属连接词 |
| sewwieq | 司机 | 阳性名词 |
| tal-karozza | 汽车的 | `ta'` + `il-karozza` 缩合 |
| tal-linja | 线路的 | `ta'` + `il-linja` 缩合；合起来即“公交车” |

**Malti:** Għażiż Sinjur / Sinjura,

**整句：** 亲爱的先生 / 女士：

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għażiż | 亲爱的 | 阳性单数形式 |
| Sinjur | 先生 | 阳性名词 |
| / | 或 | 表示二选一 |
| Sinjura | 女士 | 阴性名词 |

### 1.

**Malti:** Qed nikteb biex napplika għall-impjieg ta' sewwieq tal-karozza tal-linja.

**整句：** 我写信是为了申请公交车司机职位。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Qed | 正在（进行时标记） | 与动词连用表示正在做某事 |
| nikteb | 我写 | 第一人称单数现在时 |
| biex | 为了 | 引出目的状语 |
| napplika | 我申请 | 第一人称单数形式，借词 apply |
| għall-impjieg | 申请职位 | `għal` + `l-impjieg` 缩合 |
| ta' | ……的 | 所属连接词 |
| sewwieq | 司机 | 阳性名词 |
| tal-karozza | 汽车的 | `ta'` + `il-karozza` 缩合 |
| tal-linja | 线路的 | `ta'` + `il-linja` 缩合；合起来即“公交车” |

### 2.

**Malti:** Għandi liċenzja tas-sewqan tal-kategorija D.

**整句：** 我持有 D 类驾驶执照。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandi | 我有 | `għand` 的第一人称单数形式 |
| liċenzja | 执照 | 阴性名词，借词 licence |
| tas-sewqan | 驾驶的 | `ta'` + `is-sewqan`“驾驶”缩合 |
| tal-kategorija | 类别的 | `ta'` + `il-kategorija` 缩合 |
| D | D（类） | 指大型客车驾驶类别 |

### 3.

**Malti:** Għandi esperjenza ta' tliet snin bħala sewwieq tal-karozza tal-linja.

**整句：** 我有三年公交车司机的经验。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandi | 我有 | `għand` 的第一人称单数形式 |
| esperjenza | 经验 | 阴性名词 |
| ta' | ……的 | 所属连接词 |
| tliet | 三 | 数词，后接复数名词 |
| snin | 年 | `sena` 的复数形式 |
| bħala | 作为 | 介词 |
| sewwieq | 司机 | 阳性名词 |
| tal-karozza tal-linja | 公交车的 | 同上，“线路的车” |

### 4.

**Malti:** Naf it-toroq ta' Malta tajjeb ħafna.

**整句：** 我对马耳他的道路非常熟悉。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Naf | 我知道；我熟悉 | 第一人称单数形式 |
| it-toroq | 道路 | `triq`“路”的复数形式，带定冠词 |
| ta' | ……的 | 所属连接词 |
| Malta | 马耳他 | 地名 |
| tajjeb | 好 | 此处作副词“很好地” |
| ħafna | 非常 | 程度副词 |

### 5.

**Malti:** Jien responsabbli u jimpurtani mis-sigurtà tal-passiġġieri.

**整句：** 我负责任，并且在意乘客的安全。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jien | 我 | 第一人称单数代词 |
| responsabbli | 负责任的 | 形容词，借词 responsible |
| u | 并且 | 连词 |
| jimpurtani | 我在意 | `jimpurta` + `-ni`“我”，惯用表达 |
| mis-sigurtà | 关于安全 | `minn` + `is-sigurtà` 缩合 |
| tal-passiġġieri | 乘客的 | `ta'` + `il-passiġġieri`（复数）缩合 |

### 6.

**Malti:** Ninsab kalm u paċenzjuż mat-traffiku.

**整句：** 面对交通，我保持冷静和耐心。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Ninsab | 我处于；我保持 | 第一人称单数形式 |
| kalm | 冷静的 | 形容词 |
| u | 和 | 连词 |
| paċenzjuż | 有耐心的 | 形容词 |
| mat-traffiku | 面对交通 | `ma'` + `it-traffiku` 缩合 |

### 7.

**Malti:** Nirrispetta r-regoli tat-triq u nżomm il-ħin.

**整句：** 我遵守交通规则，并且守时。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nirrispetta | 我尊重；我遵守 | 第一人称单数形式，借词 respect |
| r-regoli | 规则 | `regola` 的复数，带定冠词 |
| tat-triq | 道路的 | `ta'` + `it-triq` 缩合；即“交通规则” |
| u | 并且 | 连词 |
| nżomm | 我保持；我遵守 | 第一人称单数形式 |
| il-ħin | 时间 | `nżomm il-ħin` 固定表达“守时” |

### 8.

**Malti:** Nispera li nisma' mingħandkom dalwaqt.

**整句：** 我希望很快收到你们的回复。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nispera | 我希望 | 第一人称单数形式 |
| li | ……；引出从句 | 连词 |
| nisma' | 我听到；收到消息 | 第一人称单数形式 |
| mingħandkom | 从你们那里 | `mingħand` + `-kom`“你们” |
| dalwaqt | 很快 | 副词 |

### 9.

**Malti:** Grazzi talli qiesu l-applikazzjoni tiegħi.

**整句：** 感谢你们考虑我的申请。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi | 谢谢 | 礼貌用语 |
| talli | 因为（你们）…… | 引出原因的书面表达 |
| qiesu | 他们考虑了 | `qies` 的第三人称复数过去时 |
| l-applikazzjoni | 申请 | 阴性名词，带定冠词 |
| tiegħi | 我的 | 所有格代词 |

**Malti:** Tislijiet, [Ismek]

**整句：** 此致敬意，[你的名字]（正式邮件落款）。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tislijiet | 此致敬意；致以问候 | 正式邮件/信件落款用语，本义"问候/致意" |
| Ismek | 你的名字 | `isem`“名字” + `-ek`“你的”；请替换为真实姓名 |
