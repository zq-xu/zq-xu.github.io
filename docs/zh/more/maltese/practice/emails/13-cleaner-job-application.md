# 清洁工求职邮件

**场景：** 申请人写信给清洁/物业公司，申请清洁工职位。

## 邮件头部

**Lil（收件人 To）：** info@tindif.com
**Mingħand（发件人 From）：** [isem]@email.com
**Data（日期）：** 15 ta' Ottubru 2026
**Suġġett（主题）：** Applikazzjoni ta' xogħol ta' haddiem tat-tindif

## 邮件全文

> **Lil:** info@tindif.com
> **Mingħand:** [isem]@email.com
> **Data:** 15 ta' Ottubru 2026
> **Suġġett:** Applikazzjoni ta' xogħol ta' haddiem tat-tindif
>
> Għażiż Sinjur / Sinjura,
>
> Qed nikteb biex napplika għall-impjieg ta' haddiem tat-tindif.
>
> Għandi esperjenza ta' sentejn fix-xogħol tat-tindif.
>
> Naf naddaf djar, uffiċini u bini ieħor.
>
> Jien bniedem li jaħdem iebes, onest u puntwali.
>
> Nista' naħdem filgħodu u filgħaxija, ukoll fi tmiem il-ġimgħa.
>
> Jimpurtani li nżomm kollox nadif u ordnat.
>
> Nispera li nisma' mingħandkom dalwaqt.
>
> Grazzi talli qiesu l-applikazzjoni tiegħi.
>
> Tislijiet,
> [Ismek]

## 逐句翻译与逐词拆解

**Malti:** Lil: info@tindif.com

**整句：** 收件人（To）：info@tindif.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Lil | 收件人；给…… | 邮件头部"To"的马耳他语标签 |
| info@tindif.com | 邮箱地址 | 清洁公司的招聘邮箱（示例） |

**Malti:** Mingħand: [isem]@email.com

**整句：** 发件人（From）：[你的名字]@email.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Mingħand | 发件人；来自…… | 邮件头部"From"的马耳他语标签，本义"从……那里" |
| [isem]@email.com | 邮箱地址 | 你的邮箱占位，请替换为真实邮箱 |

**Malti:** Data: 15 ta' Ottubru 2026

**整句：** 日期：2026 年 10 月 15 日

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Data | 日期 | 邮件头部"Date"；马耳他语日期格式为"日 ta' 月 年" |
| 15 | 十五 | 日期中的日 |
| ta' | ……的 | 连接日和月份 |
| Ottubru | 十月 | 月份名 |

**Malti:** Suġġett: Applikazzjoni ta' xogħol ta' haddiem tat-tindif

**整句：** 主题：清洁工职位申请

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Suġġett | 主题 | 邮件头部"Subject" |
| Applikazzjoni | 申请 | 阴性名词，借词 application |
| ta' | ……的 | 所属连接词 |
| xogħol | 工作；职位 | 阳性名词 |
| ta' | ……的 | 所属连接词 |
| haddiem | 工人 | 阳性名词 |
| tat-tindif | 清洁的 | `ta'` + `it-tindif` 缩合 |

**Malti:** Għażiż Sinjur / Sinjura,

**整句：** 亲爱的先生 / 女士：

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għażiż | 亲爱的 | 阳性单数形式 |
| Sinjur | 先生 | 阳性名词 |
| / | 或 | 表示二选一 |
| Sinjura | 女士 | 阴性名词 |

### 1.

**Malti:** Qed nikteb biex napplika għall-impjieg ta' haddiem tat-tindif.

**整句：** 我写信是为了申请清洁工职位。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Qed | 正在（进行时标记） | 与动词连用表示正在做某事 |
| nikteb | 我写 | 第一人称单数现在时 |
| biex | 为了 | 引出目的状语 |
| napplika | 我申请 | 第一人称单数形式，借词 apply |
| għall-impjieg | 申请职位 | `għal` + `l-impjieg` 缩合 |
| ta' | ……的 | 所属连接词 |
| haddiem | 工人 | 阳性名词 |
| tat-tindif | 清洁的 | `ta'` + `it-tindif` 缩合 |

### 2.

**Malti:** Għandi esperjenza ta' sentejn fix-xogħol tat-tindif.

**整句：** 我有两年的清洁工作经验。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandi | 我有 | `għand` 的第一人称单数形式 |
| esperjenza | 经验 | 阴性名词 |
| ta' | ……的 | 所属连接词 |
| sentejn | 两年 | `sentejn`“两年”的固定形式 |
| fix-xogħol | 在工作方面 | `f'` + `ix-xogħol` 缩合 |
| tat-tindif | 清洁的 | `ta'` + `it-tindif` 缩合 |

### 3.

**Malti:** Naf naddaf djar, uffiċini u bini ieħor.

**整句：** 我会打扫房屋、办公室和其他建筑。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Naf | 我知道；我会 | 第一人称单数形式 |
| naddaf | 我清洁；我打扫 | 第一人称单数现在时 |
| djar | 房屋 | `dar`“房子”的复数形式 |
| uffiċini | 办公室 | `uffiċċju` 的复数形式 |
| u | 和 | 连词 |
| bini | 建筑 | 集合名词 |
| ieħor | 其他的 | 阳性单数形式 |

### 4.

**Malti:** Jien bniedem li jaħdem iebes, onest u puntwali.

**整句：** 我是一个勤劳、诚实且守时的人。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jien | 我 | 第一人称单数代词 |
| bniedem | 人 | 阳性名词 |
| li | ……的；引出关系从句 | 关系代词 |
| jaħdem | 他工作 | 第三人称阳性单数 |
| iebes | 努力地；刻苦的 | 此处作副词“努力地” |
| onest | 诚实的 | 形容词，借词 honest |
| u | 和 | 连词 |
| puntwali | 守时的；准时的 | 形容词，借词 punctual |

### 5.

**Malti:** Nista' naħdem filgħodu u filgħaxija, ukoll fi tmiem il-ġimgħa.

**整句：** 我可以上午和晚上工作，周末也可以。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nista' | 我能 | 第一人称单数形式 |
| naħdem | 我工作 | 第一人称单数现在时 |
| filgħodu | 在上午 | 时间表达 |
| u | 和 | 连词 |
| filgħaxija | 在晚上 | 时间表达 |
| ukoll | 也 | 副词 |
| fi | 在……里 | 介词 `f'` 的变体 |
| tmiem | 结束；末尾 | `tmiem il-ġimgħa` 固定表达“周末” |
| il-ġimgħa | 星期 | 阴性名词，带定冠词 |

### 6.

**Malti:** Jimpurtani li nżomm kollox nadif u ordnat.

**整句：** 我在意保持一切干净整齐。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jimpurtani | 我在意 | `jimpurta` + `-ni`“我”，惯用表达 |
| li | ……；引出从句 | 连词 |
| nżomm | 我保持 | 第一人称单数形式 |
| kollox | 一切；所有东西 | 不定代词 |
| nadif | 干净的 | 阳性单数形容词 |
| u | 和 | 连词 |
| ordnat | 整齐的；有序的 | 形容词，借词 ordinate |

### 7.

**Malti:** Nispera li nisma' mingħandkom dalwaqt.

**整句：** 我希望很快收到你们的回复。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nispera | 我希望 | 第一人称单数形式 |
| li | ……；引出从句 | 连词 |
| nisma' | 我听到；收到消息 | 第一人称单数形式 |
| mingħandkom | 从你们那里 | `mingħand` + `-kom`“你们” |
| dalwaqt | 很快 | 副词 |

### 8.

**Malti:** Grazzi talli qiesu l-applikazzjoni tiegħi.

**整句：** 感谢你们考虑我的申请。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi | 谢谢 | 礼貌用语 |
| talli | 因为（你们）…… | 引出原因的书面表达 |
| qiesu | 他们考虑了 | `qies` 的第三人称复数过去时 |
| l-applikazzjoni | 申请 | 阴性名词，带定冠词 |
| tiegħi | 我的 | 所有格代词 |

**Malti:** Tislijiet, [Ismek]

**整句：** 此致敬意，[你的名字]（正式邮件落款）。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tislijiet | 此致敬意；致以问候 | 正式邮件/信件落款用语，本义"问候/致意" |
| Ismek | 你的名字 | `isem`“名字” + `-ek`“你的”；请替换为真实姓名 |
