# 酒店前台求职邮件

**场景：** 申请人写信给酒店（也可用于银行），申请前台接待职位。

## 邮件头部

**Lil（收件人 To）：** info@lukanda.com
**Mingħand（发件人 From）：** [isem]@email.com
**Data（日期）：** 15 ta' Ottubru 2026
**Suġġett（主题）：** Applikazzjoni ta' xogħol ta' receptionist

## 邮件全文

> **Lil:** info@lukanda.com
> **Mingħand:** [isem]@email.com
> **Data:** 15 ta' Ottubru 2026
> **Suġġett:** Applikazzjoni ta' xogħol ta' receptionist
>

>

## 逐句翻译与逐词拆解

**Malti:** Lil: info@lukanda.com

**整句：** 收件人（To）：info@lukanda.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Lil | 收件人；给…… | 邮件头部"To"的马耳他语标签 |
| info@lukanda.com | 邮箱地址 | 酒店的招聘邮箱（示例） |

**Malti:** Mingħand: [isem]@email.com

**整句：** 发件人（From）：[你的名字]@email.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Mingħand | 发件人；来自…… | 邮件头部"From"的马耳他语标签，本义"从……那里" |
| [isem]@email.com | 邮箱地址 | 你的邮箱占位，请替换为真实邮箱 |

**Malti:** Data: 15 ta' Ottubru 2026

**整句：** 日期：2026 年 10 月 15 日

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Data | 日期 | 邮件头部"Date"；马耳他语日期格式为"日 ta' 月 年" |
| 15 | 十五 | 日期中的日 |
| ta' | ……的 | 连接日和月份 |
| Ottubru | 十月 | 月份名 |

**Malti:** Suġġett: Applikazzjoni ta' xogħol ta' receptionist

**整句：** 主题：前台接待职位申请

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Suġġett | 主题 | 邮件头部"Subject" |
| Applikazzjoni | 申请 | 阴性名词，借词 application |
| ta' | ……的 | 所属连接词 |
| xogħol | 工作；职位 | 阳性名词 |
| ta' | ……的 | 所属连接词 |
| receptionist | 前台接待；前台职员 | 借词 receptionist |

**Malti:** Għażiż Sinjur / Sinjura,

**整句：** 亲爱的先生 / 女士：

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għażiż | 亲爱的 | 阳性单数形式 |
| Sinjur | 先生 | 阳性名词 |
| / | 或 | 表示二选一 |
| Sinjura | 女士 | 阴性名词 |

### 1.

**Malti:** Qed nikteb biex napplika għall-impjieg ta' receptionist.

**整句：** 我写信是为了申请前台接待职位。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Qed | 正在（进行时标记） | 与动词连用表示正在做某事 |
| nikteb | 我写 | 第一人称单数现在时 |
| biex | 为了 | 引出目的状语 |
| napplika | 我申请 | 第一人称单数形式，借词 apply |
| għall-impjieg | 申请职位 | `għal` + `l-impjieg` 缩合 |
| ta' | ……的 | 所属连接词 |
| receptionist | 前台接待 | 借词 receptionist |

### 2.

**Malti:** Għandi esperjenza ta' tliet snin fis-servizz tal-klijenti.

**整句：** 我有三年的顾客服务经验。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandi | 我有 | `għand` 的第一人称单数形式 |
| esperjenza | 经验 | 阴性名词 |
| ta' | ……的 | 所属连接词 |
| tliet | 三 | 数词，后接复数名词 |
| snin | 年 | `sena` 的复数形式 |
| fis-servizz | 在服务方面 | `f'` + `is-servizz` 缩合 |
| tal-klijenti | 顾客的 | `ta'` + `il-klijenti`（复数）缩合 |

### 3.

**Malti:** Naf nitkellem Malti, Ingliż u ftit Taljan.

**整句：** 我会说马耳他语、英语和一点意大利语。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Naf | 我知道；我会 | 第一人称单数形式 |
| nitkellem | 我说话 | 第一人称单数形式 |
| Malti | 马耳他语 | 语言名 |
| Ingliż | 英语 | 语言名 |
| u | 和 | 连词 |
| ftit | 一点；少量 | 数量词 |
| Taljan | 意大利语 | 语言名 |

### 4.

**Malti:** Nista' nwieġeb it-telefon u nilqa' lill-klijenti b'mod edukat.

**整句：** 我能接听电话，并礼貌地接待顾客。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nista' | 我能 | 第一人称单数形式 |
| nwieġeb | 我回答；我接（电话） | 第一人称单数形式 |
| it-telefon | 电话 | 阳性名词，带定冠词 |
| u | 并且 | 连词 |
| nilqa' | 我接待；我迎接 | 第一人称单数形式 |
| lill-klijenti | 给顾客们 | `li` + `l-klijenti` 缩合，引出宾语 |
| b'mod | 以……方式 | `b'`“以” + `mod`“方式” |
| edukat | 有礼貌的 | 形容词 |

### 5.

**Malti:** Jien nadif, puntwali u responsabbli.

**整句：** 我整洁、守时且负责任。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jien | 我 | 第一人称单数代词 |
| nadif | 整洁的；干净的 | 形容词 |
| puntwali | 守时的；准时的 | 形容词，借词 punctual |
| u | 和 | 连词 |
| responsabbli | 负责任的 | 形容词，借词 responsible |

### 6.

**Malti:** Nista' naħdem billejl u fi tmiem il-ġimgħa.

**整句：** 我可以上夜班，也可以在周末工作。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nista' | 我能 | 第一人称单数形式 |
| naħdem | 我工作 | 第一人称单数现在时 |
| billejl | 在夜间 | `bil-lejl`“在晚上”的缩合形式 |
| u | 和 | 连词 |
| fi | 在……里 | 介词 `f'` 的变体 |
| tmiem | 结束；末尾 | `tmiem il-ġimgħa` 固定表达“周末” |
| il-ġimgħa | 星期 | 阴性名词，带定冠词 |

### 7.

**Malti:** Naf nuża l-kompjuter u nittratta mal-flus b'attenzjoni.

**整句：** 我会使用电脑，并小心地处理钱款。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Naf | 我知道；我会 | 第一人称单数形式 |
| nuża | 我使用 | 第一人称单数形式 |
| l-kompjuter | 电脑 | 阳性名词，带定冠词 |
| u | 并且 | 连词 |
| nittratta | 我处理；我对待 | 第一人称单数形式，借词 treat |
| mal-flus | 与钱款 | `ma'` + `il-flus`（复数）缩合 |
| b'attenzjoni | 小心地；注意地 | `b'` + `attenzjoni`“注意” |

### 8.

**Malti:** Nispera li nisma' mingħandkom dalwaqt.

**整句：** 我希望很快收到你们的回复。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nispera | 我希望 | 第一人称单数形式 |
| li | ……；引出从句 | 连词 |
| nisma' | 我听到；收到消息 | 第一人称单数形式 |
| mingħandkom | 从你们那里 | `mingħand` + `-kom`“你们” |
| dalwaqt | 很快 | 副词 |

### 9.

**Malti:** Grazzi talli qiesu l-applikazzjoni tiegħi.

**整句：** 感谢你们考虑我的申请。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi | 谢谢 | 礼貌用语 |
| talli | 因为（你们）…… | 引出原因的书面表达 |
| qiesu | 他们考虑了 | `qies` 的第三人称复数过去时 |
| l-applikazzjoni | 申请 | 阴性名词，带定冠词 |
| tiegħi | 我的 | 所有格代词 |

**Malti:** Tislijiet, [Ismek]

**整句：** 此致敬意，[你的名字]（正式邮件落款）。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tislijiet | 此致敬意；致以问候 | 正式邮件/信件落款用语，本义"问候/致意" |
| Ismek | 你的名字 | `isem`“名字” + `-ek`“你的”；请替换为真实姓名 |
