# 教师求职邮件

**场景：** 申请人写信给学校，申请教师职位。

## 邮件头部

**Lil（收件人 To）：** info@skola.com
**Mingħand（发件人 From）：** [isem]@email.com
**Data（日期）：** 15 ta' Ottubru 2026
**Suġġett（主题）：** Applikazzjoni ta' xogħol ta' għalliem

## 逐句翻译与逐词拆解

**Malti:** Lil: info@skola.com

**整句：** 收件人（To）：info@skola.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Lil | 收件人；给…… | 邮件头部"To"的马耳他语标签 |
| info@skola.com | 邮箱地址 | 学校的招聘邮箱（示例） |

**Malti:** Mingħand: [isem]@email.com

**整句：** 发件人（From）：[你的名字]@email.com

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Mingħand | 发件人；来自…… | 邮件头部"From"的马耳他语标签，本义"从……那里" |
| [isem]@email.com | 邮箱地址 | 你的邮箱占位，请替换为真实邮箱 |

**Malti:** Data: 15 ta' Ottubru 2026

**整句：** 日期：2026 年 10 月 15 日

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Data | 日期 | 邮件头部"Date"；马耳他语日期格式为"日 ta' 月 年" |
| 15 | 十五 | 日期中的日 |
| ta' | ……的 | 连接日和月份 |
| Ottubru | 十月 | 月份名 |

**Malti:** Suġġett: Applikazzjoni ta' xogħol ta' għalliem

**整句：** 主题：教师职位申请

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Suġġett | 主题 | 邮件头部"Subject" |
| Applikazzjoni | 申请 | 阴性名词，借词 application |
| ta' | ……的 | 所属连接词 |
| xogħol | 工作；职位 | 阳性名词 |
| ta' | ……的 | 所属连接词 |
| għalliem | 教师 | 阳性名词；女性教师为 `għalliema` |

**Malti:** Għażiż Sinjur / Sinjura,

**整句：** 亲爱的先生 / 女士：

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għażiż | 亲爱的 | 阳性单数形式 |
| Sinjur | 先生 | 阳性名词 |
| / | 或 | 表示二选一 |
| Sinjura | 女士 | 阴性名词 |

### 1.

**Malti:** Qed nikteb biex napplika għall-impjieg ta' għalliem.

**整句：** 我写信是为了申请教师职位。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Qed | 正在（进行时标记） | 与动词连用表示正在做某事 |
| nikteb | 我写 | 第一人称单数现在时 |
| biex | 为了 | 引出目的状语 |
| napplika | 我申请 | 第一人称单数形式，借词 apply |
| għall-impjieg | 申请职位 | `għal` + `l-impjieg` 缩合 |
| ta' | ……的 | 所属连接词 |
| għalliem | 教师 | 阳性名词 |

### 2.

**Malti:** Għandi lawrja fl-edukazzjoni u esperjenza ta' sentejn fit-tagħlim.

**整句：** 我有教育学位和两年的教学经验。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandi | 我有 | `għand` 的第一人称单数形式 |
| lawrja | 学位 | 阴性名词，借词 laurea |
| fl-edukazzjoni | 在教育方面 | `f'` + `l-edukazzjoni` 缩合 |
| u | 和 | 连词 |
| esperjenza | 经验 | 阴性名词 |
| ta' | ……的 | 所属连接词 |
| sentejn | 两年 | `sentejn`“两年”的固定形式 |
| fit-tagħlim | 在教学方面 | `f'` + `it-tagħlim` 缩合 |

### 3.

**Malti:** Naf ngħallem il-Malti, l-Ingliż u l-matematika.

**整句：** 我会教马耳他语、英语和数学。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Naf | 我知道；我会 | 第一人称单数形式 |
| ngħallem | 我教 | 第一人称单数形式 |
| il-Malti | 马耳他语 | 语言名，带定冠词 |
| l-Ingliż | 英语 | 语言名，带定冠词 |
| u | 和 | 连词 |
| l-matematika | 数学 | 阴性名词，带定冠词 |

### 4.

**Malti:** Jien paċenzjuż u nħobb naħdem mat-tfal.

**整句：** 我有耐心，并且喜欢和孩子们一起工作。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jien | 我 | 第一人称单数代词 |
| paċenzjuż | 有耐心的 | 形容词 |
| u | 并且 | 连词 |
| nħobb | 我喜欢 | 第一人称单数形式 |
| naħdem | 我工作 | 第一人称单数现在时 |
| mat-tfal | 和孩子们 | `ma'` + `it-tfal` 缩合 |

### 5.

**Malti:** Nipprepara l-lezzjonijiet b'mod kreattiv u ċar.

**整句：** 我以富有创造性和清晰的方式备课。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nipprepara | 我准备 | 第一人称单数形式 |
| l-lezzjonijiet | 课程 | `lezzjoni`“课”的复数，带定冠词 |
| b'mod | 以……方式 | `b'` + `mod`“方式” |
| kreattiv | 有创造性的 | 形容词，借词 creative |
| u | 和 | 连词 |
| ċar | 清晰的 | 形容词 |

### 6.

**Malti:** Jimpurtani mill-progress ta' kull student.

**整句：** 我在意每个学生的进步。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jimpurtani | 我在意 | `jimpurta` + `-ni`“我”，惯用表达 |
| mill-progress | 关于进步 | `minn` + `il-progress` 缩合 |
| ta' | ……的 | 所属连接词 |
| kull | 每一个 | 限定词 |
| student | 学生 | 阳性名词，借词 student |

### 7.

**Malti:** Nista' naħdem ukoll ma' adulti fi klassijiet ta' filgħaxija.

**整句：** 我也可以在晚间班级与成人一起工作。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nista' | 我能 | 第一人称单数形式 |
| naħdem | 我工作 | 第一人称单数现在时 |
| ukoll | 也 | 副词 |
| ma' | 和；与 | 介词 |
| adulti | 成年人 | `adult` 的复数形式，借词 adult |
| fi | 在……里 | 介词 `f'` 的变体 |
| klassijiet | 班级 | `klassi`“班”的复数形式 |
| ta' | ……的；在……时段 | 连接名词和时间表达 |
| filgħaxija | 在晚上 | 时间表达 |

### 8.

**Malti:** Nispera li nisma' mingħandkom dalwaqt.

**整句：** 我希望很快收到你们的回复。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nispera | 我希望 | 第一人称单数形式 |
| li | ……；引出从句 | 连词 |
| nisma' | 我听到；收到消息 | 第一人称单数形式 |
| mingħandkom | 从你们那里 | `mingħand` + `-kom`“你们” |
| dalwaqt | 很快 | 副词 |

### 9.

**Malti:** Grazzi talli qiesu l-applikazzjoni tiegħi.

**整句：** 感谢你们考虑我的申请。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi | 谢谢 | 礼貌用语 |
| talli | 因为（你们）…… | 引出原因的书面表达 |
| qiesu | 他们考虑了 | `qies` 的第三人称复数过去时 |
| l-applikazzjoni | 申请 | 阴性名词，带定冠词 |
| tiegħi | 我的 | 所有格代词 |

**Malti:** Tislijiet, [Ismek]

**整句：** 此致敬意，[你的名字]（正式邮件落款）。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tislijiet | 此致敬意；致以问候 | 正式邮件/信件落款用语，本义"问候/致意" |
| Ismek | 你的名字 | `isem`“名字” + `-ek`“你的”；请替换为真实姓名 |
