# 生日聚会邀请（教材听力练习）

**场景：** Anna 给 Maria 写邮件，邀请她来参加自己在 Għadira 湾举行的 15 岁生日聚会。这是 PDF 中的教材原文邮件，括号内为听力填空选项。

## 邮件头部

**Lil（收件人 To）：** maria.b@gmail.com
**Mingħand（发件人 From）：** anna.c@gmail.com
**Data（日期）：** 30 ta' Ġunju, 2023
**Suġġett（主题）：** Festin ta' għeluq snini

### 1.

### 2.

**Malti:** Nispera li tinsab tajba.

**整句：** 希望你一切都好。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nispera | 我希望 | 第一人称单数 |
| li | ……；引出从句 | 连词 |
| tinsab | 你处于；你在 | `tinsab` 第二人称 |
| tajba | 好的 | 阴性单数形容词 |

### 3.

**Malti:** Bħalma taf, (ilbieraħ / dalwaqt / sena oħra) se nagħlaq 15-il sena u qed nibgħatek din l-ittra elettronika sabiex nistednek għall-festin ta' għeluq snini.

**整句：** 如你所知，（昨天 / 很快 / 另一年）我就满 15 岁了，我发这封邮件是为了邀请你来参加我的生日聚会。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Bħalma | 正如 | `bħal`+`ma` |
| taf | 你知道 | 第二人称单数 |
| ilbieraħ | 昨天 | 听力选项① |
| dalwaqt | 很快 | 听力选项② |
| sena oħra | 另一年；再一年 | 听力选项③ |
| se | 将要 | 将来时标记 |
| nagħlaq | 我满（岁） | 字面"关闭"，指岁数届满 |
| 15-il sena | 15 岁 | 数字+`-il`+sena 的结构 |
| qed | 正在 | 进行时标记 |
| nibgħatek | 我发给你 | `nibgħat`+`-ek`（你） |
| din | 这 | 阴性指示代词 |
| l-ittra elettronika | 电子邮件 | ittra（信）+elettronika（电子的） |
| sabiex | 为了 | 书面连词 |
| nistednek | 我邀请你 | `nistedin`+`-ek` |
| għall-festin | 来参加聚会 | `għal`+`il-festin` |
| ta' għeluq snini | 我生日的 | għeluq（生日）+snin（复数"岁"）+-i（我的） |

### 4.

**Malti:** Il-festin se jkun nhar (il-ġimgħa l-oħra / ix-xahar id-dieħel / il-Ġimgħa 14 ta' Lulju).

**整句：** 聚会将在（下周 / 下个月 / 7 月 14 日星期五）那天举行。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Il-festin | 聚会 | `festin` 小型聚会，借词 |
| se jkun | 将会是 | 将来时 |
| nhar | 在……那天 | 字面"天" |
| il-ġimgħa l-oħra | 下周 | 选项① |
| ix-xahar id-dieħel | 下个月 | 选项②：字面"进入的月份" |
| il-Ġimgħa 14 ta' Lulju | 7 月 14 日星期五 | 选项③ |

### 5.

**Malti:** Fis- (tmienja ta' flgħaxija / sitta ta' flgħodu / sitta ta' flgħaxija) se niltaqgħu (quddiem / fuq / taħt) il-knisja biex minn hemm niġru bil-van kollha f'daqqa li se joħodna l-bajja tal-Għadira.

**整句：** 我们将在（晚上 8 点 / 早上 6 点 / 晚上 6 点）在（教堂前 / 教堂上 / 教堂下）见面，然后一起坐面包车去 Għadira 海滩。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| tmienja ta' flgħaxija | 晚上八点 | 选项①（`filgħaxija`） |
| sitta ta' flgħodu | 早上六点 | 选项②（`filgħodu`） |
| sitta ta' flgħaxija | 晚上六点 | 选项③ |
| quddiem | 前面 | 选项①方位 |
| fuq | 上面 | 选项② |
| taħt | 下面 | 选项③ |
| il-knisja | 教堂 | 阴性名词，带定冠词 |
| biex | 为了 | 目的连词 |
| minn hemm | 从那里 | 地点短语 |
| niġru | 我们乘车疾驰 | `iġri` 第一人称复数 |
| bil-van | 坐面包车 | `b'`+`il-van` |
| kollha f'daqqa | 大家一起 | kollha（全部）+f'daqqa（一下子） |
| se joħodna | 将带我们 | `jieħu`（带）+-na（我们） |
| l-bajja tal-Għadira | Għadira 海滩 | bajja（海滩）+ta'（的）+Għadira（地名） |

### 6.

**Malti:** Fil-festin se jkun hemm ħafna ikel, xorb, logħob u mużika!

**整句：** 聚会上将会有很多食物、饮料、游戏和音乐！

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Fil-festin | 在聚会上 | `f'`+`il-festin` |
| se jkun hemm | 将会有 | 存在结构 |
| ħafna | 很多 | 数量词 |
| ikel | 食物 | 阳性名词 |
| xorb | 饮料 | 名词 |
| logħob | 游戏 | 名词 |
| mużika | 音乐 | 借词 music |

### 7.

**Malti:** Tinsiex tiġi bil-malja u ġġib xugaman għax xi qabża l-baħar ma tonqosx!

**整句：** 别忘了穿泳衣、带毛巾，因为下水游泳是少不了的！

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Tinsiex | 别忘了 | `tinsa`+`x`，祈使否定 |
| tiġi | 你来 | 第二人称单数 |
| bil-malja | 穿泳衣 | `b'`+`il-malja`（malja 泳衣） |
| u | 并且 | 连词 |
| ġġib | 你带 | 第二人称单数 |
| xugaman | 毛巾 | 借词 |
| għax | 因为 | 原因连词 |
| xi | 某种 | 限定词 |
| qabża l-baħar | 跳进海里 | qabża（跳）+l-baħar（海） |
| ma tonqosx | 不会缺；少不了 | `ma`+`tonqos`+`x` 否定 |

### 8.

**Malti:** Jekk jogħġbok agħtini risposta sa (bħal-lum ġimgħa / xahar ieħor).

**整句：** 请在一周内（/再过一个月）给我答复。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jekk jogħġbok | 请 | 字面"如果你乐意" |
| agħtini | 给我 | `agħti`（给）+-ni（我） |
| risposta | 答复 | 借词 risposta |
| sa | 到……为止 | 介词 |
| bħal-lum ġimgħa | 一周后的今天 | 选项①（OCR 另有乱码项，疑为 `il-biċċa l-oħra`，存疑） |
| xahar ieħor | 再过一个月 | 选项② |

### 9.

**Malti:** Nispera li narak ħalli nieħdu gost flimkien!
