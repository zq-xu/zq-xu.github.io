# 厨师求职信（教材写作模板）

**场景：** 申请人给餐厅写信申请厨师职位。这是 PDF 中的教材原文模板，括号内为填空选项。注意：原文落款印刷为 `Tisjiet`，规范正式拼写为 `Tislijiet`。

## 邮件头部

**Lil（收件人 To）：** info@restorant.com
**Mingħand（发件人 From）：** gorg.com.mt
**Data（日期）：** 16 ta' Ottubru 2026
**Suġġett（主题）：** Applikazzjoni ta' xogħol ta' kok

## 逐句翻译与逐词拆解

**Malti:** Lil: info@restorant.com

**整句：** 收件人（To）：info@restorant.com

**Malti:** Mingħand: gorg.com.mt

**整句：** 发件人（From）：gorg.com.mt

| 词语 | 中文含义 | 说明 |

| Mingħand | 发件人；来自…… | 邮件头部"From"的马耳他语标签 |
| gorg.com.mt | 邮箱地址 | 发件人示例邮箱（Gorg） |

**Malti:** Data: 16 ta' Ottubru 2026

### 1.

### 2.

**Malti:** Jien qiegħed nibgħatlek din l-ittra biex (napplika / tapplika) għal xogħol.

**整句：** 我写这封信是为了（申请 / 你申请）工作。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jien | 我 | 第一人称代词 |
| qiegħed | 正在 | 进行时标记（阳性） |
| nibgħatlek | 我发给你 | `nibgħat`+`-lek` |
| din l-ittra | 这封信 | din（这）+ittra（信） |
| biex | 为了 | 目的连词 |
| napplika | 我申请 | 选项①：借词 apply 第一人称 |
| tapplika | 你申请 | 选项②：第二人称 |
| għal xogħol | 为了工作 | għal（为了）+xogħol（工作） |

### 3.

**Malti:** Nispera li tinsab tajjeb. Qed nibgħatlek din l-ittra elettronika sabiex napplika għal xogħol ta' kok fir-restorant tiegħek.

**整句：** 希望你安好。我发这封邮件是为了申请您餐厅的厨师职位。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nispera | 我希望 | 第一人称单数 |
| li | 引出从句 | 连词 |
| tinsab | 你处于 | 第二人称 |
| tajjeb | 好 | 副词/形容词 |
| Qed | 正在 | 进行时标记 |
| nibgħatlek | 我发给你 | 见上 |
| din l-ittra elettronika | 这封电子邮件 | ittra+elettronika |
| sabiex | 为了 | 书面连词 |
| napplika | 我申请 | 第一人称 |
| għal xogħol ta' kok | 应聘厨师工作 | kok（厨师，借词 cook） |
| fir-restorant | 在餐厅 | `f'`+`ir-restorant` |
| tiegħek | 你的 | 阳性所有格 |

### 4.

**Malti:** Jien nixtieq naħdem bħala kok għax inħobb insajjar, inħobb naħdem ma' ħaddieħor u nħobb niltaqa' man-nies.

**整句：** 我想当厨师，因为我喜欢做饭、喜欢和别人一起工作、喜欢和人打交道。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Jien | 我 | 代词 |
| nixtieq | 我想要 | 第一人称单数 |
| naħdem | 我工作 | 第一人称单数 |
| bħala | 作为 | 介词 |
| kok | 厨师 | 借词 cook |
| għax | 因为 | 原因连词 |
| inħobb | 我喜欢 | 第一人称单数 |
| insajjar | 我做饭 | 第一人称单数 |
| ma' ħaddieħor | 和其他人 | ħaddieħor（别人） |
| u | 和 | 连词 |
| niltaqa' | 我见面；打交道 | 第一人称单数 |
| man-nies | 和人 | `ma'`+`in-nies`（人们） |

### 5.

**Malti:** Kont immur l-iskola tal-ITS (institute of tourism studies) u minn hemm ġibt iċ-ċertifikati li kelli bżonn.

**整句：** 我上过 ITS（旅游学院），从那里拿到了我需要的证书。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Kont | 我曾经 | 过去时助动词 |
| immur | 我去 | 第一人称单数 |
| l-iskola | 学校 | 阴性名词，带定冠词 |
| tal-ITS | ITS 的 | `ta'`+`l-ITS`（旅游学院） |
| minn hemm | 从那里 | 地点短语 |
| ġibt | 我拿到；我带来 | 第一人称单数过去时 |
| iċ-ċertifikati | 证书 | `ċertifikat` 复数，带定冠词 |
| li | 那些 | 关系代词 |
| kelli bżonn | 我需要 | `kell`（有）+`bżonn`（需要） |

### 6.

**Malti:** Għandi esperjenza ta' ħames snin naħdem f'restorant ta' lukanda lussuża.

**整句：** 我有五年在豪华酒店餐厅工作的经验。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Għandi | 我有 | `għand` 第一人称 |
| esperjenza | 经验 | 阴性名词 |
| ta' ħames snin | 五年的 | ħames（五）+snin（年） |
| naħdem | 我工作 | 第一人称单数 |
| f'restorant | 在餐厅 | `f'`+restorant |
| ta' lukanda | 酒店的 | lukanda（酒店） |
| lussuża | 豪华的 | 阴性形容词 |

### 7.

**Malti:** u għalhekk naħseb li kapaċi għal dan ix-xogħol. Naf nitkellem Ingliż, Malti, u ftit Taljan.

**整句：** 因此我认为我能胜任这份工作。我会说英语、马耳他语和一点意大利语。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| għalhekk | 因此 | `għal`+`hekk` |
| naħseb | 我认为 | 第一人称单数 |
| li | 引出从句 | 连词 |
| kapaċi | 有能力的 | 借词 capable |
| għal dan ix-xogħol | 胜任这份工作 | dan（这）+xogħol（工作） |
| Naf | 我会；我知道 | 第一人称单数 |
| nitkellem | 我说话 | 第一人称单数 |
| Ingliż | 英语 | 语言名 |
| Malti | 马耳他语 | 语言名 |

### 8.

**Malti:** Grazzi talli qrajt din l-ittra. Napprezza jekk tikkunsidrani għal dan ix-xogħol.

**整句：** 谢谢您读这封信。如果您考虑我应聘这份工作，我将很感激。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Grazzi | 谢谢 | 礼貌用语 |
| talli | 因为（您）…… | 书面原因表达 |
| qrajt | 您读了 | `qara` 第二人称单数过去时 |
| din l-ittra | 这封信 | 见上 |
| Napprezza | 我感激 | 借词 appreciate |
| jekk | 如果 | 条件连词 |
| tikkunsidrani | 您考虑我 | `tikkunsidra`+`-ni` |
| għal dan ix-xogħol | 应聘这份工作 | 见上 |

### 9.

**Malti:** Nista' niltaqa' miegħek biex nikkellmu iktar fid-dettall kuljum mit-8 ta' filgħodu sas-7 ta' filgħaxija. / meta tkun komdu inti.

**整句：** 我可以每天上午 8 点到晚上 7 点和您见面详谈。/ 或者您方便的时候。

| 词语 | 中文含义 | 说明 |
|---|---|---|
| Nista' | 我能 | 第一人称单数 |
| niltaqa' | 我见面 | 第一人称单数 |
| miegħek | 和您 | `ma'`+`-ek` |
| biex | 为了 | 目的连词 |
| nikkellmu | 我们谈 | `kellem` 第一人称复数 |
| iktar | 更多；更 | 比较级副词 |
| fid-dettall | 详细地 | `f'`+`id-dettall`（细节） |
| kuljum | 每天 | 副词 |
| mit-8 ta' filgħodu | 从上午 8 点 | `minn`+`it-8` |
| sas-7 ta' filgħaxija | 到晚上 7 点 | `sa`+`is-7` |
| meta | 当……时 | 时间连词 |
| tkun komdu | 您方便 | tkun（是）+komdu（舒适/方便） |
| inti | 您 | 第二人称代词 |
